## 2. 算法对象与可部署信息

在缓冲打开的服务器版本 t，冻结全端旧缓存 \(h_i^-\)、源版本 \(s_i^h\)、重建残差范数和最近确认消息。单客户端只允许一项在途任务、每缓冲最多一条有效贡献。

\[
H_t=N^{-1}\sum_i h_i^-,\quad
q_i=Q_k(d_i(\theta_{s_i})-h_i^-),\quad
h_i^+=h_i^-+\mathrm{decode}(q_i),\quad u_i=h_i^+-h_i^-.
\]

浮点实现以双方一致的实际重建差 \(u_i\) 聚合，不把舍入前的数学 q 当作逐比特恒等。分组在本缓冲任何返回前冻结：ID 从 0 起升序遍历，按创建顺序检查已有组；与组内每个成员的余弦均不小于 0.8 时加入第一个合格组，否则新建单元素组。零范数不能强行定义余弦。总体分区为 \(G_j\)，\(\pi_j=|G_j|/N\)，本缓冲组返回人数 \(m_j\)，\(f_j=m_j/B\)。这是旧实现的确定性 complete-link 规则，不让 Executor 另选聚类程序。[提交：d35871b；文件：direction_b/qualify.py 的 groups]

\[
v_C=H_t+B^{-1}\sum_{i\in\mathcal B}u_i,\qquad
v_R=H_t+\sum_j\pi_j\bar u_j,\qquad
v_R-v_C=\sum_j(\pi_j-f_j)\bar u_j.
\]

全端缓存必须已知、范数大于 \(10^{-12}\)、旧残差比不大于 0.25、旧缓存源年龄不超过 \(\tau_{\max}=2\lceil N/B\rceil\)。旧残差比定义为最近确认时的实际重建误差范数除以 \(\max(\|h_i^-\|,10^{-12})\)，不是当前未返回梯度的误差；年龄为 \(t-s_i^h\)。任意一项不满足，或任意总体组没有返回，整个缓冲回退 C。不得只删不利端再改目标。只有一组、比例相等或新增变化为零时自然无修正。[提交：d35871b；文件：direction_b/qualify.py 的 gate；年龄窗口是本阶段设计]

本阶段 N=20、B=4，故年龄上限为 10；旧二维单缓冲的 2 不直接搬到连续二十端系统。一次遍历至少需要五个缓冲，把 2 硬搬过来可能结构性关闭全部缓存门控。取两遍历窗口是事前尺度选择，不保证异步时延满足它，也不允许看到结果再扩大。其余门控沿旧定义。

条件于分组和各组人数、组内独立简单抽样且无压缩/年龄误差时，R 对全端当前方向条件无偏；MSE 是否下降还取决于组内新增变化方差。自然异步返回不自动满足交换性。E01 直接测所有返回及失败边界，不把余弦阈值当无偏证明。分组与新增变化不相容、组内返回偏差、历史压缩误分组都可能使方法失败。[推断；旧修订论证的条件推导]

### 状态与编码

高维实现是新实现，旧二维代码不直接充当通过证明。梯度来自 float32 模型；缓存和聚合用 float64。上传数值体为 float32，稀疏索引用 uint32，元数据含 epoch、端号、序号、基准序号、源版本、维度、编码类型及残差范数。Top-k 留绝对值最大的 \(\max(1,\lceil kD\rceil)\) 坐标，并列取索引小者；k=1 使用稠密编码。残差在实际解码重建之后计算。

客户端先保存 pending；服务器提交缓存、去重信息和缓冲贡献后才确认。重复同序号同内容只补确认，内容冲突/错误基准拒收。保存双方状态、在途源版本、缓冲开始快照、消费状态与自身费用增量；恢复不重复贡献、不重算已完成科学对象。只重验维度、精度、模型与事件接入改变的部分，不重建旧 R01 封存框架。

\[
F_i(\theta)=|S_i|^{-1}\sum_{(x,y)\in S_i}\mathrm{CE}(f_\theta(x),y),\quad
F=N^{-1}\sum_iF_i,\quad d_i(\theta)=\nabla_\theta F_i(\theta).

### 4.2 连续异步事件，不能逐缓冲重新暖初始化

初始全端各启动一项任务，源版本为 0。端 i 的每项服务时间为 \(a_i U[0.9,1.1]\)；偶数 ID 的 a=1、奇数 ID 的 a=3，不读标签或梯度来安排快慢。各端用 Random(seed+1000*i) 按自己的任务序号抽抖动；种子固定 2026102101 至 2026102104。它是受控系统异构模拟，不是宿主实测速度。

按完成时钟、再按 ID 排序接收；一个缓冲收满四个不同端后消费、服务器版本加一。已贡献端在缓冲消费后才启动下一任务，源版本为新版本；其余端保留原在途任务及源版本。每条轨迹运行 16 个缓冲，缓存、pending、时钟和版本跨缓冲延续；最后一个缓冲消费后不再启动新任务。当前目标总是公共路径上的 \(g_t=N^{-1}\sum_i d_i(\theta_t)\)，迟到包仍只含 \(d_i(\theta_{s_i})\)。

压力矩阵：异构服务 × k={0.10 主点、1.00 无压缩、0.01 压缩边界}，另等服务 a=1 × k=0.10；每项四条事件轨迹，共 16 条轨迹、256 缓冲、1,024 条有效返回。各算法共享到达与源版本，梯度表只生成一次。等服务只去掉设备档位差，不保证有限返回估计误差为零。

### 4.3 必须保留的对照与诊断

- C：相同重建，无分组缓存校准。
- CACHE：接收后的全端缓存均值，即 \(H_t+N^{-1}\sum_{i\in\mathcal B}u_i\)。
- ABS：相同缓存分组，对返回端的绝对重建状态按总体占比分层，即 \(\sum_j\pi_j m_j^{-1}\sum_{i\in G_j\cap\mathcal B}h_i^+\)；相同门控/缺组回退 C。
- MSG：残差分层但按最近确认消息分组；每个零消息各自成为单元素组。分组规则、缓存资格门控与 R 相同，覆盖条件按 MSG 自己的分区判断。
- ID：ID 0–9 / 10–19 固定分层；相同缓存资格门控，按自己的分区判断缺组并回退 C。
- AVG：返回端绝对重建状态的均值，仅作普通缓冲对照，不冠以原版文献算法名。
- Ucur：本次消息取消压缩、沿用 R 的旧缓存/分组/源版本；只诊断当前压缩损失。
- Uhist：同事件完整无压缩历史重放，自己的缓存和分组；与 R 的门控变化单列，在共同合格端上另报余弦阈值边与分区差异。不得把不同门控分母混成压缩收益。

前六项与 R 是实际信息下的比较；后两项和全端真值是诊断，不算免费可部署方法。总体目标、初始化与唯一贡献规则一致；自然 C 可删去不需要的残差元数据，须另计其自然部署成本。

### 4.4 主判据与停止

每条轨迹的主量为 \(\mathrm{MSE}_X=16^{-1}\sum_{t=0}^{15}\|v_X(t)-g_t\|^2\)，包括首次零变化、门控关闭和缺组回退。另报全路径相对目标能量、偏差、最大误差、实际非零修正比例、组数、缺组/过龄/残差回退率、组内变化离散与到达组成。零分母标未定义，不加任意小常数改变意义。

主组仅为异构服务/k=0.10，**以下同时成立才通过**：

1. 输入、参考、维度/编码、过去顺序与恢复不变量有效。
2. 四轨迹平均 MSE 的 R 相对 C、CACHE、ABS **各降低至少 5%**；且每个比较至少三条轨迹的差值为正，超出数值容差。基线误差为零而无严格改善，不能判独立收益通过。
3. 主组 64 个缓冲中实际非零修正不少于 20%，不是靠全程回退 C 获得“无损通过”。
4. 所有边界和诊断完整保留。主组不满足不能改用 k=1、k=0.01、等服务或 Uhist 宣布通过。

5% 与 20% 是本轮事前探索的实用筛选线，不是显著性或文献保证；四条事件轨迹不叫四个独立训练种子。聚合算术用 float64，误差量比较容差取 \(\epsilon=10^{-8}\max(1,\mathrm{mean}_t\|g_t\|^2)\)。配对改善要求 \(\mathrm{MSE}_{baseline}-\mathrm{MSE}_R>\epsilon\)；非零修正要求 \(\|v_R-v_C\|^2>\epsilon\)，各自使用所在轨迹的 \(\epsilon\)。算术参照检查也比较差向量的平方范数，不能把平方误差容差直接当向量范数容差；超过容差先判测量无效，不能靠改成功线修理。至少 20% 对 64 缓冲即至少 13 个实际非零缓冲。

若分组数常大于 B、门控几乎总关闭、变化与分组无关、CACHE 解释全部收益或只有无损诊断胜出，主判据会失败：停止当前 B，保留接口与负结果。已经知道的这些可能性不是允许看到结果后封顶组数、扩大年龄或重抽端的理由。
