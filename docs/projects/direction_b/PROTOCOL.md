## 固定算法和对照

所有分组在缓冲打开时冻结。全体缓存有记录、范数大于 `1e-12`、残差比不超过 `0.25`、源版本年龄不超过 `2` 时才允许修正；否则整缓冲回退 C。完整总体组必须各有返回，否则回退 C。分组为按 ID 递增的 complete-link 余弦规则，阈值 `0.8`。

- C：全端旧缓存均值 + 返回端新增变化均值。
- R：全端旧缓存均值 + 按总体组占比加权的组内新增变化均值。
- CACHE：接收后全端缓存均值。
- ABS：相同缓存分组、相同总体组占比，对返回端绝对新状态分层平均；缺组时回退 C。
- MSG：算法 R，但分组依据为全体端最近确认的差分消息。零消息各自成组；只改变分组依据。
- ID：算法 R，但按 ID 前后各半固定分组；是简单分层控制，不是文献算法。
- U：同一冻结缓存分组、同一返回/源版本，取消本次上传压缩的 R 诊断；额外当前向量只在评价侧，不馈入 R。

所有端一次缓冲最多一条有效贡献、一个未确认包；同序号重复包只重发 ACK。保存客户端 pending、服务器已提交状态、旧快照、buffer、消费状态及成本增量。浮点标准 JSON 保存；稀疏载荷 `uint32 index + float64 value`，稠密载荷 `float64`，元数据 UTF-8 JSON 加 uint32 长度；按编码字节计账。

## 已冻结的输入与工作量

六端、二维、每缓冲三个不同端。A 类型 ID 为 `0,2,4`，B 类型为 `1,3,5`，避免类型直接等于连续 ID 分组。每个单元枚举 `C(6,3)=20` 个返回集合，从同一个初始快照分别出发，不将枚举样本当独立训练种子。

三个缓存幅值依次为 `0.75,1,1.25`；齐次缓存则均为 `1`。A 缓存沿第一坐标，B 沿第二坐标。暖初始化先全量传一个中间状态 `h-(0.125,0)`，再传真实 Top1 差分 `(0.125,0)` 达到指定缓存。这同时构造了确实可达、方向不代表缓存的最近消息；初始化和确认全计费。

六个输入族：

1. `coherent`：齐次缓存；A 新增 `(0.5,0)`，B 新增 `(0,0.5)`。
2. `heterogeneous_cache`：异幅缓存；新增与上项相同。**差分相对绝对分层的主对照。**
3. `mixed_increment`：异幅缓存；A 新增 `(0.5,0.125)`，B 新增 `(0.125,0.5)`。**有非零压缩误差的主对照。**
4. `common_increment`：异幅缓存；所有端新增 `(0.25,0.25)`，检验无组间变化差异的零效应。
5. `unrelated_increment`：异幅缓存；按 ID 固定新增 `(0.5,0),(-0.5,0),(0,0.5),(0,-0.5),(-0.5,0),(0.5,0)`，不期待相似度必有收益。
6. `stationary`：异幅缓存；新增全零，检验准确缓存。

各族交叉：恒等/Top1 两压缩；fresh/aged 两源版本，共 `6×2×2=24` 单元、`480` 个缓冲、`1440` 条正式有效返回。当前参考版本 `2`；fresh 所有端源版本 `2`；aged 的 B 端源版本 `0`，其可见新增变化设为当前新增的一半，A 端保持不变。这是固定潜在向量表，不是实测设备速度或优化轨迹。当前全端目标固定为 `mean(h + 当前新增)`，算法只见返回端可见新增。

补充固定控制：旧三步 Top1 跟踪；旧准确缓存反例；冷缓存；缺组；全端返回；组内返回有偏；年龄/残差门控；错误基准/重复包。偏差反控制使用 A 新增全零，B ID `1,3,5` 新增分别 `(0,1),(0,-0.5),(0,-0.5)`，固定返回 `{0,2,1}`；该返回不满足组内交换条件，预期 R 的目标误差可能高于 C，必须保留。

代表周期只先运行 `heterogeneous_cache / Top1 / fresh` 一个完整单元、上述控制、一次保存退出恢复；不根据其分数调整正式输入或参数。代表周期的同一单元正式阶段通过身份校验复用，余下 `23` 单元执行一次。

## 判据与输出

主指标为平方误差 `||v-g||²`。按单元报告全部 20 集合及 R 实际生效集合的均值、最大值、偏差向量、回退率；不得仅报告生效子集掩盖回退。主资格：

1. 状态、重复、确认、消费和恢复的关键不变量通过；无数值/身份失效。
2. `heterogeneous_cache/fresh` 的 R 平均误差低于 C 和 ABS；`mixed_increment/fresh/Top1` 仍低于 C，比较含回退的全部集合，同时另报 U。
3. 准确缓存、全参与、冷启动/缺组规定回退正确；不能通过全局禁用修正取得“无损通过”。
4. 组内偏差反控制必须揭示不适用边界，不将其删掉。其他压力不要求 R 逐点占优。

阈值只为算术容差 `1e-10 * max(1, ||g||²)`，不设数据驱动百分点。穷举是给定有限总体的精确枚举，不产生总体泛化置信区间。真实精度、尾类召回和总通信效率未检验。

记录约定（首次运行前固定）：`r_eligible` 表示门控满足且所有组覆盖，是“生效子集”的分母；`r_nonzero` 另记修正是否实际非零，不能把静止情况下的合法零修正写成关门。每个反事实缓冲均独立付费初始化，通信总表是独立场景之和，不冒充一条时间连续训练轨迹。U 只取消本次压缩，不重新生成无损历史分组，因此不把它叫完整无压缩状态诊断。

输出 `artifacts/direction_b/r01_v1/`：每单元 JSON、控制与恢复结果、输入/实现身份、资源账、汇总。摘要和四栏结果写 `TO_REVIEWER.md`；STATE/DECISIONS 更新当前决定。
