这次只补偿各组“新变化”的代表比例：总体里一半客户端属于某组，即使本次返回里它占三分之二，也不让它的新变化占三分之二。每组内部返回仍要具有代表性；组内本身有偏时，这个办法也会失效。

当前只用很小的数学例子和消息协议检查这一点，不训练模型。最重要的比较是：不分组的缓存校准、直接平均缓存、普通分层，以及本次对新增变化分层。通过后仍不能说论文完成或实验精度更好。
