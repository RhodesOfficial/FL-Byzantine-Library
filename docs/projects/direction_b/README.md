# 给作者看的说明

B 原来把相似客户端“合并后再等权”，可能再次改坏已校准的平均方向。

这次只补偿各组“新变化”的代表比例：总体里一半客户端属于某组，即使本次返回里它占三分之二，也不让它的新变化占三分之二。每组内部返回仍要具有代表性；组内本身有偏时，这个办法也会失效。

这次检查已经完成。在事先选定的条件内，新方法优于不分组的缓存校准和普通分层；但缓存相似却不代表新变化相似时，它更差。每组内部的返回偏向某些客户端时，它也会加重误差。这些负结果都保留了。

因此 B 值得保留为一个有限候选，当前还没有真实模型精度或通信省钱的证据，也没有证明硕士论文创新够格。本轮只做小向量和消息恢复检查，没有训练。结果详见 [交付与下一步](R01_RESULT.md)；下一项真正待解决的问题是：上述有利条件在自然研究场景中是否会发生。当前任务已结束，没有自动开启后续实验。
