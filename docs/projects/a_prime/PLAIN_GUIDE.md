## 为什么这次停止

这次已经确认两件有用的事：新设定确实造成了更新来源失配；原来的 C100 r80 特征在新规定的头优化下，也能提供可利用的分类信息。

但第三件关键的事没有成立：加上概率校正后，误差虽然比“不用缓存的逆概率加权”低，却比“只用过去缓存”高很多。主比较中三者分别为 0.234948、0.624719、0.084025。即使用真正的完成概率，误差也仍高于仅缓存。不能只保留胜过较弱对照的一半结果。

因此这次主要失败在“复杂方法是否值得用”，并非又因为特征没有信息或机器跑不动。校正可以减少偏差，也会增加波动；在本次预先固定的比较里，代价超过收益。

## 哪些成果还能用

可以引用新机制的受控失配证据、固定参考的探索性表征结果、估计器的正负对照，以及保存/恢复和完整周期预算的经验。它们都要带上原参考、数据、目标和适用边界。

真实头的尾类召回 11.76% 来自全端训练特征上的诊断求解，不是 A′ 联邦算法的准确率，也不会改写旧 P 的失败。本次没有跑方法各自更新后的训练轨迹，所以不能把结果说成所有缓存校正方法都无效。

结果分支已经推送，但被 Git 忽略的本地特征、事件和优化器对象仍需保留；推送本身不等于这些大文件已有备份。
