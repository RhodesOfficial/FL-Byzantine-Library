## 只读恢复验证

使用已有 Python310 与 [外层入口](../../../scripts/run_a_prime_e02.ps1)：

```powershell
& scripts/run_a_prime_e02.ps1 -Mode verify -Seconds 60
```

该命令只能在包完整且尚未完成此验证时调用。完成验证拒绝再次重复。它检查 [最终三态](../../../artifacts/a_prime/e02/state.json)、必要对象身份、两头优化器和对应节点参数、每头累计调用／接受迭代及全部证据哈希，不重新训练、评价、抽事件或重算梯度。实际本次是否通过，以 [读回证据](../../../artifacts/a_prime/e02/recovery_verification.json) 和对应外层回执为准。

大产物保存在 `artifacts_local/a_prime/e02/`，被 Git 忽略；[身份记录](../../../artifacts/a_prime/e02/input_identity.json) 和 [读回证据](../../../artifacts/a_prime/e02/recovery_verification.json) 保存路径、字节身份和引用。必须保留这些本地文件；**不声称只凭当前 Git 提交就能恢复优化器／事件原数组**。必要输入可按锁定 `ba9b542` 的两个具体对象恢复，不拷历史整包。

## 中断不被冒充完成

- 每接受步保存头／优化器状态；另有每头调用 journal，使未接受线搜索已经消费的调用不因进程恢复清零。若 journal 损坏，拒绝恢复，不补零。
- 代表阶段在头求解开始前的初始化错误可限内修复，复用已通过检查和已完整输入。头开始后的代表失败及正式科学阶段失败均交部分；外层入口禁止隐含重复。保存完成检查点之前的断电／超时可能只留临时状态，本次**未测试所有断电位置**，不会从旧检查点偷偷重做已接受步。
- 动态事件部分阶段已有梯度节点时，不自动重算它们。完整事件 JSON 可由封包代码只读续封，但真正部分事件与完成事件严格区分；继续科学计算需先有可验证的剩余边界，不因低分恢复。
- 限额是共享1800秒程序墙时／8GiB OS工作集／512MiB新增本地产物；内层计时只作分项，不与外层回执再次相加。修复和读取也共享总包，未定义更大范围不开放。

本次测试的恢复是“代表部分优化器跨进程续算＋包完整后的独立读回”，不是全故障点容错认证或工程创新。E03、其他参考与独立确认仍未开始。
