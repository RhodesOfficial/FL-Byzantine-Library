## 1. 可直接引用的两个案例

### B：能写出分层公式，不等于实际缓冲能触发分层

**事实：**B-EXP-v1 在固定 C10/r80 全模型公共梯度路径上，按旧缓存分组，要求每个总体组都有返回才能修正。主组每缓冲四端，却分成十一至十四组；64/64 必然缺组，新增修正 0/64，所有边界合计 0/256。R、无分组 C、绝对分层 ABS 的主平均 MSE 同为 1.7809342723130015；相对纯缓存的约 28.6700592443% 改善由 C 同样取得。[文件：29b1e26:docs/projects/b/DECISIONS.md，B-D03；artifacts/b/e01/summary.json]

**可引用结论：**要求全组覆盖时，组数 J≤缓冲不同客户端数 b 是必要条件；必须在真实输入上确认新增机制有实际触发机会。全程回退只否定这个固定候选的可生效增量资格，不能证明激活后无效或缓存与新增变化普遍无关。分类效用和独立确认未检验。[推断]；[文件：同上]

**固定入口：**科学裁决 29b1e260bd222135dc4f10eee5f1ba235b573ee9，交付父提交 be91af41461b8a67a83639b337f4a1a57276316e；完整复盘 a7d6a00:docs/DIRECTION_B_POSTMORTEM_AND_NEXT_STEP_v1.md；原数据留 codex/direction-b 的 artifacts/b/e01/，必要二进制按其清单留本地。master 不复制该包。[提交]

### A′：校正比一个弱基线好，不等于比最直接的简单办法好

**事实：**A′ 固定公共头路径的实际概率＋缓存估计，比无缓存 IPW 的误差降低 62.3914%，却比仅缓存增加 179.6162%；真实概率诊断仍劣于仅缓存。受控失配和新规定下的线性头表征资格可以保留，联合估计增量没有成立。[文件继承：1e5257d:docs/DIRECTION_A_POSTMORTEM_AND_NEXT_STEP_v2.md，§3–4；该报告所引 6f49bc5 的 E02 summary]

**可引用结论：**改善偏差、使用更准信息或增加一个合理模块，不自动改善总风险。必须包含能解释改进的直接简单对照。保留正证据和负证据各自的对象，不把探针分数写成联邦方法准确率，也不把新探针通过追认成旧 P 通过。[推断]；[文件继承：上述 v2]

该引用是已有复盘的二级索引；需要精确公式/结果时按其固定来源读取。A′ 的 E03 仍关闭，master 不复制其运行合同。

## 2. 后续立项要问的六个问题

|问题|最低可检查证据|不能用什么替代|
|---|---|---|
|目标和信息可识别吗？|相同观测是否允许两个相反正确答案；未来/缺失对象是否被当作免费输入。|“坐标统一”“公式无偏”或 oracle 好看。|
|新增机制能触发吗？|数量、容量、支持域、秩/维度及门控的必要条件；真实代表输入的触发与回退计数。|只在人工例子中触发，或无论何时都退回简单基线。|
|触发后有独立增量吗？|A 单独、B 单独、最直接删模块对照、简单替代和必要 oracle 各自用途明确。|只赢较弱对照；把共同退化当机制等价。|
|实际观察测到了这个问题吗？|给所有回退、空组、零变化和未开始对象的分母；区分条件效应与触发率。|把单样本方差 0 说成确定，把缺组 null 补成好看的 0。|
|能否转为所声称的效用？|各方法自身轨迹、匹配的评价目标、同成本比较；探索和独立确认分开。|公共路径估计误差、全端诊断头、四个事件种子充当最终训练证据。|
|一整包是否值得且做得完？|代表读取/计算/保存/恢复后一次冻结剩余包；科学停止优先于余额。|只估一轮计算、反复为保存追加、把未知峰值填零。|

这些是从案例归纳的检查问题 [推断]，不是要求每个方向新增六轮审批。能在同一纸面论证、代表周期或审结中回答，就在同一单回答。

### 三个常被混淆的推论

1. J≤b 只说明全组覆盖没有被数量直接排除；仍需检查实际返回是否覆盖。一个早期缓冲关闭也不能证明整个动态路径都会关闭。[推断]
2. 缓存向量相似只约束缓存，不约束下一步变化；没有新增信息的数学前提，不能从一个余弦阈值推出后续方差降低。[推断]
3. 若 v_D=v_0+I·δ 且 I 全为 0，观察到 v_D=v_0 说明本任务没有检验激活后的 δ。可以停止固定候选，不能把结论扩成任何 δ 都无用。[推断]

## 3. 哪些流程这次有效，哪些仍需警惕

- **有效：**在新结果前固定强对照和失败出口；B 首次完整审结就停止，E02/E03 没有因余额继续。A′ 的缓存强对照也阻止了只保留对 IPW 的改善。[文件：两份关闭复盘]
- **有效：**费用自身增量只并一次；保存恢复继承已完成对象。B 已记录 151.7354445 秒、最终留存 698,295,742 B、采样 OS 工作集最大 1,438,093,312 B；这些不是人工总工时、完整磁盘/内存峰值或论文成本。[文件：29b1e26:docs/projects/b/RESOURCE_LEDGER.json]
- **要提前：**先写容量/支持必要条件和机制可触发范围，再完善数值认证。B 的门控风险曾被正确预判；后续应使风险成为可观察记录，而非只列在风险段落。[文件：e2aa349:docs/projects/b/PROTOCOL.md §4.4]；[推断]
- **不误判轮数：**实现、冻结、读回、换行修复的提交数不等于研究交付往返。应数科学问题、完整交付和审结，不用文件版本号制造进展或制造超限。[文件：B-D03]；[推断]
- **不用失误掩盖失败：**同周期修复报告范围/字节保存，不意味着主科学结论无效；相反，有足够主证据就不必补齐所有辅助表格才能停止。[文件：两份关闭复盘]；[推断]
