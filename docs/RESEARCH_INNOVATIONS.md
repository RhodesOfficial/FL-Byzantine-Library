## 方向一：类别覆盖约束的根信任与限额残差聚合

### 1. 创新点假设

**【拟议设计／待验证】提出“类别覆盖约束的鲁棒聚合”算法 D1，针对《Xiao 等 - 2026 - Divergence-Based Adaptive Aggregation for Byzantine Robust Federated Learning.pdf》的根方向对齐前提、《非独立同分布场景下的鲁棒联邦学习方法研究_王晨.pdf》的整体效用筛选盲区，以及《面向非独立同分布数据的联邦学习方法研究_李卫超.pdf》的长尾方法未建模攻击这一缺口，在有限根数据和可陈述的污染假设下，减少尾类良性更新被误抑制，同时限制根集未覆盖方向的投毒影响。**

这里的“解决”是一个条件性假设：核心目标是缓解根偏差和抗投毒的冲突；不承诺在“恶意多数、尾类完全无可信信息”下恢复尾类。

### 2. 核心思路

**三类线索及其证据。**

| 线索 | 证据与推导 |
|---|---|
| 相互批判 | 【来自定向查阅原文】P5 p2 的 Related Work 批评若干鲁棒聚合在高恶意比例及异质非凸设定下的局限；但 P5 自身 p5–6 又依赖可信根方向、良性更新相对范数有界，以及良性更新与根方向的加权对齐条件。T2 p51 §4.3.1 明确批评余弦筛选会把异质但重要的良性客户端排除。**【基于文献基座的推断】**这形成“多数统计可能被污染 → 根方向提供可信性 → 根方向失配又可能伤害稀有良性方向”的三角矛盾，并非 P5 与 T2 相互引用。 |
| Future Work 延伸 | 【来自定向查阅原文】T6 p67 §5.3 提出进一步利用客户端的特征差异改进聚合。将这种差异意识推进到“根集覆盖不均且存在攻击”的场景，是本文的延伸。P5 p10 的实际 Future Work 是去中心化，**没有**把根集缺类写成 Future Work。 |
| 通用机制嫁接 | 【拟议设计／待验证】嫁接任务梯度子空间分解、类别级约束和保守回退机制。它们共同处理“哪些方向有可信证据、哪些方向只能有限采纳”，不额外堆叠生成器或复杂注意力网络。 |

**要同时处理的 x、y、z：**x 是根方向有偏时误伤良性异质更新；y 是整体精度掩盖尾类损伤；z 是直接放开根集未覆盖方向会给投毒留下通道。根集无污染是本方向的显式前提，根标签本身被篡改另列失效条件。

**模块 A：建立类别级根证据，而非只有一个整体根方向。**

将固定预算的可信根数据分为根训练集和独立审计集。对每个类别记录样本数、损失波动和梯度稳定性，形成可靠度 `q_c`；缺类设为 0。用可靠类别的根损失梯度 `g_c` 构成子空间，记其正交投影为 `P`。同时构造类别均衡的根更新 `r`，避免根集中的大类仅凭数量决定方向。

`q_c` 是可实现的可靠度启发式，不能直接称为具有覆盖率保证的统计置信度。客户端自报的类别数或样本数不用于授予信任。类别全集由任务定义提供，服务端不需要知道客户端的真实良恶性或真实尾类分布。

**模块 B：可信子空间内校准，剩余方向限额保留。**

服务端先把所有上传更新裁剪到范数 `B`，再分解为：

\[
\Delta_i^{\parallel}=P\Delta_i,\qquad
e_i=(I-P)\Delta_i.
\]

在可信子空间内，以现有 BR-DRAG 校准为起点得到 `u_R`；对子空间外残差计算几何中位数 `e_hat`，生成候选更新：

\[
\widehat\Delta(\lambda)=u_R+\lambda\widehat e,
\qquad \|\lambda\widehat e\|\le b.
\]

残差并不等于尾类梯度，也不自动可信。它只是根数据没有充分约束的一部分更新，有可能包含有价值的稀有类信息。残差聚合的有效性需要**有效参与更新中良性质量占多数，且良性残差离散程度受控**；整体 30% 恶意不自动意味着每轮都满足该条件，必须记录每轮实际比例。

**模块 C：类别损失约束决定残差预算，并允许回退。**

从小型固定候选集合选择 `lambda` 和步长，将最终候选位移统一裁剪到范数 `B`，先要求可靠根类别的一阶增量 `g_c^T Delta <= epsilon_c`，再在独立根审计集上检验每个有足够证据的类别：

\[
L_c(w+\widehat\Delta)-L_c(w)\le\epsilon_c.
\]

以宏平均损失改善选择可行候选，而不是只看总体准确率；没有可行候选时缩小步长，仍不满足则尝试保守根更新，根更新也不满足约束时跳过该次更新。缺类不能通过这一检验，所以其对应的不确定性不能成为“自动放大残差预算”的理由。

必须分别报告两个预先声明的运行模式：

- **多数良性模式，主实验：**在有效污染低于 1/2 的条件下启用有限残差预算，检验能否保留尾类信息。
- **根信任保守模式，高恶意压力实验：**不依赖残差多数，禁用未经独立证据支持的残差，并以根更新为保守回退。该模式可能牺牲缺失尾类，不宣称同时解决所有缺类情形。不能根据实验中已知的真实恶意身份偷偷切换模式。

**为什么能够协同？**模块 A 决定可信证据覆盖的方向，模块 B 只在剩余方向保留受限的多样性，模块 C 再约束这部分多样性对已覆盖类别的实际损伤。残差与根梯度一阶正交，并不意味着完整模型的类别损失不变，模块 C 因而有真实作用。若只有 A，根偏差仍会压制未覆盖信息；若只有 B，残差可成为攻击通道；若没有 C，保留尾类与破坏已覆盖类之间没有可检验的控制条件。三个模块围绕同一个“证据覆盖范围”变量形成闭环。

**新意应落在哪：**类别约束决定“子空间内校准、子空间外限额保留”的不同处理方式，以及缺类时的明确回退边界。仅把根评分、异常评分、长尾损失相加，不足以成立。

### 3. 最小实验设计

以下均为 **【拟议设计／待验证】**，不是照抄原文的默认参数。

| 项目 | 最小配置 |
|---|---|
| 数据集与模型 | CIFAR-10-LT / 小型 CNN；CIFAR-100-LT / ResNet18。它们是 2 个基础数据集的长尾划分，不另算额外数据集；主实验长尾不平衡比 50。 |
| 客户端与训练 | 100 端，每轮随机 20 端；Dirichlet `alpha=0.1` 为主，`0.5` 作单因素补充；200 轮、本地 1 epoch、4 个种子。先用无攻击预实验确认训练长度足够，再固定全部方法预算。 |
| 根数据 | 总预算 2000 条，根训练与审计各 1000 条；从训练池预先隔离，所有根方法共享相同总预算。完整覆盖和缺失 20% 类别为主，缺类同时作用于根训练与审计集；各条件保持总样本数相同。 |
| 攻击 | 全标签翻转用于对标 T2；根方向约束下的自适应模型投毒，用于保持根效用同时破坏尾类；固定触发器后门，用于检查正常效用筛选的盲区。无攻击是必需对照。 |
| 恶意比例 | 主设定 30%；在 CIFAR-10-LT 补 10% 和 60%。60% 必须报告上述运行模式及缺类代价，不与 30% 的条件性结论混写。 |
| 对照 | FedAvg、FLTrust、BR-DRAG、FLEST、仅将 BR-DRAG 的根训练改成类别均衡的版本，共 5 个对照。最后一个用于排除“只是重采样根数据”的解释。 |
| 核心指标 | 干净测试总体准确率、宏平均准确率、预先按训练类频次划分的尾类准确率、后门 ASR、尾类客户端与其他良性客户端的有效聚合权重、回退比例、根计算成本。软加权方法不能伪造二元误拒率，应同时报告有效权重损失。 |

**控制工作量：**两个数据集只跑 6 个主场景：完整根/无攻击、缺类根/无攻击、完整根/翻标、完整根/自适应、缺类根/自适应、缺类根/后门。缺类率 `{0%,20%,50%}`、根预算 `{500,2000,3000}`、恶意比例扫描只在 CIFAR-10-LT 的代表性攻击下分别进行，不取全笛卡尔积。

**必要消融：**完整版；A 改为单一整体根方向；B 直接丢弃残差；C 改为整体平均损失约束；以及“类别均衡 BR-DRAG + 普通残差混合”的直接拼接对照。删除模块时维持根数据、训练和调参预算相同。重点检验：完整版能否在相近 ASR/总体准确率下，比直接拼接方法保留更多尾类性能。

这对标 T1 的 3 模块/2 集，以及 T2 的 2 集/恶意比例和偏斜扫描；不复刻 T6 的全部长尾数据集。

### 4. 预期能证明什么

**【基于文献基座的推断】**对应空白区“P5/T2 已做高恶意比例，但根集缺类/漂移时的尾类保护未证实”。本方向首先填补其中的**根集缺类与类别比例失配**分支；不把它推广成对任意概念漂移的结论。

如果实验成立，可支持：在给定根预算、有效良性多数及有限缺类条件下，类别覆盖约束比整体方向/效用评分更好地平衡尾类保留和投毒抑制；并能给出“覆盖率—恶意比例—尾类性能”的经验失效边界。

理论上可先证明一个有限的局部结论：若真实类别损失为 `L`-光滑，根梯度估计误差不超过 `xi_c`，且候选位移满足 `g_c^T Delta <= epsilon_c`、`||Delta||<=B`，则该类别单步损失增量至多为：

\[
\epsilon_c+\xi_cB+\tfrac{L}{2}B^2.
\]

这是待核实假设下的损失变化界，不是后门检测保证，也不适用于根集中完全没有证据的类别。理论工作不必扩张成任意恶意比例下的全局最优收敛证明。

**否证条件：**若仅类别均衡 BR-DRAG 就获得同样效果，或尾类提升主要来自放行更多后门，则核心机制没有得到支持。平均准确率提高而尾类更差，也不能算成功。

### 5. 最可能在哪里翻车（风险预判）

| 失效条件 | 原因及规避 |
|---|---|
| 根集完全缺少尾类，恶意客户端又在残差中占多数 | 缺少可信信号，残差中位数可被控制。只能收缩主张、回退或补充明确计入预算的可信样本；不能靠伪标签自动创造可信根。 |
| 高置信根梯度仍然有系统偏差 | 样本内稳定性不代表目标分布代表性。须加入根类别比例失配及一种特征偏移压力测试，并单独标注其范围，不等同真实概念漂移。 |
| 根数据来源被攻破或标签被系统篡改 | 类别约束会保护错误目标。可信根来源是显式前提；根污染压力测试只用于暴露边界，不能以自身审计结果证明根数据干净。 |
| 各类约束冲突，算法频繁跳过更新 | 类别保护可能导致训练停滞。采用有限容差和步长缩减，报告回退率与尾类收益；如大部分更新被跳过，考虑缩小受保护类别集合，不能只延长训练掩盖问题。 |
| 攻击者在审计集上表现正常 | 有限根集看不到所有后门与分布外行为。白盒攻击应知道规则和根数据；ASR 必须实测，不能由审计损失推断。 |
| 与已有根信任融合方法高度重合 | **【补充一手检索】**FLTrust 已研究根分布偏差，FLEST 已融合根信任与异常检测。因此“根集有偏”和“双评分融合”都不是新发现；必须证明子空间处理与类别约束的增量。[FLTrust 原文](https://www.ndss-symposium.org/wp-content/uploads/2021-434-paper.pdf)、[FLEST 出版页及摘要](https://www.mdpi.com/2079-9292/12/13/2926)。 |

## 方向二：源版本条件检测与跨时间贡献预算

### 1. 创新点假设

**【拟议设计／待验证】提出“源版本与贡献预算联合防御”算法 D2，针对《Fang 等 - 2026 - A Byzantine-robust asynchronous federated learning method on Non-IID data.pdf》中自适应攻击只修改当前梯度的验证范围，以及《非独立同分布场景下的联邦学习鲁棒性的优化研究_谈轩.pdf》的历史一致性假设，在不使用根数据的条件下同时缓解“陈旧良性更新被误判、延迟掩护恶意更新、持续提交污染历史”三个问题。**

### 2. 核心思路

**三类线索及其证据。**

| 线索 | 证据与推导 |
|---|---|
| 相互批判 | 【来自定向查阅原文】P1 p2 批评仅做陈旧度加权不足以消除方向偏差，也指出良性延迟更新和恶意更新都可能偏离当前参考。P1 p9 §5.1.2 明确其自适应攻击只攻击当前梯度、保持延迟梯度不变；p10 描述延迟检测阈值的放宽。**【基于文献基座的推断】**T1 的历史一致性可帮助识别偶发异常，但历史也可能被低强度持续攻击污染；“允许慢端偏离”与“防止攻击者利用容忍区间”存在冲突。 |
| Future Work 延伸 | 【来自定向查阅原文】P1 p15 §6 明确提出引入丢包、时延方差和带宽波动等网络层模拟。本文沿这一线索加入攻击者控制的提交时间；“联合优化延迟与投毒”是本文进一步推导，不冒称作者原话。 |
| 通用机制嫁接 | 【拟议设计／待验证】嫁接条件残差建模、稳健在线记忆和滚动贡献预算。检测与限额都绑定服务端记录的源模型版本和时间窗口，避免只有一个“越旧越宽松”的分数。 |

**显式威胁模型：**服务器可信，可看到单个更新；客户端具有稳定且受准入约束的身份。攻击者可控制恶意客户端的更新向量和提交时间，可快发、延迟、串谋；不能伪造服务器签发的模型版本和任务编号，也不能无限新增身份。签发记录证明收到过哪个版本，**不证明客户端确实诚实训练了该版本**。D2 不同时处理 D3 的身份轮换问题。

**模块 A：按源版本解释更新，再迁移到当前版本。**

服务器保存短窗口内每个源版本的稳健参考 `m_s`，并维护每个客户端的低维历史偏差 `b_i`。当源于模型版本 `s` 的更新 `Delta_i` 在 `t` 到达时，先计算：

\[
z_{i,s}=\phi(\Delta_i)-\phi(m_s)-b_i.
\]

`phi` 使用按层的低维投影及范数统计；根据源版本历史的稳健尺度标准化残差。这样衡量的是“相对于当时预期行为的异常”，而非直接拿陈旧更新与当前均值比较。判断异常之后，再以限幅的一阶近似 `Delta_i + (m_t-m_s)` 做陈旧度补偿；这个近似只在客户端偏差变化缓慢时合理，不能称为精确反事实梯度。

服务端保留有限个完整版本参考，客户端历史只存低维统计；不存储每个客户端的所有完整梯度。超出可用参考窗口的更新保守丢弃或重新发起训练，不无限外推。

**模块 B：使历史的更新服从与当前模型一致的信任约束。**

参考使用前一阶段已经接受的数据，并在评分时排除该客户端自身对参考的即时影响；通过稳健中心、限幅和小步长更新记忆。新提交不能先移动参考再用移动后的参考证明自己正常。冷启动用当前缓冲区的稳健统计，不假设存在一段无攻击预热期。

这仍依赖窗口内可辨识的良性统计：正常数据突然变化和缓慢投毒可能相似，所以“历史通过”不等于永久可信。历史更新幅度也受下一模块的预算约束，使攻击者不能以几乎不影响当前聚合的提交悄悄重写检测参考。

**模块 C：限制一个客户端跨窗口累计造成的影响。**

对已补偿更新再次做完整范数裁剪，并对每个稳定身份设置滚动窗口贡献预算：

\[
\sum_{t\in W}a_{i,t}\le\beta,
\qquad a_{i,t}\ge0,\qquad
\|\widetilde\Delta_{i,t}\|\le B.
\]

同时给短时间内集中到达的同一源版本批次设总预算，防止攒积后集中释放。异常评分决定候选权重，预算决定最多能接受多少；用截断后的绝对权重更新，不在剔除其他更新后将剩余恶意权重重新归一到 1。预算不足时减少本次步长或等待新证据。每个身份的未完成任务数也设上限，攻击者的发送速度因此不能直接变成聚合权重。

**为什么能够协同？**A 将合法陈旧度从异常残差中分离，避免为了保留慢端而普遍放宽阈值；B 让 A 依赖的历史不被新提交立即改写；C 限制重复的小幅漏检在模型和记忆中的累积。三个模块共同约束同一条时间序列中的影响，而不是把“检测器、滑窗、限流器”各自独立接上。去掉 A 会误伤正常慢端；去掉 B 会让 A 的预测基准逐步偏移；去掉 C 则单次微弱异常可以靠频率放大。

**新意应落在哪：**源版本条件残差与历史更新共用贡献预算，及其在“快发污染参考”和“蓄积延迟投毒”两种相反策略下的作用。单纯增加延迟权重、滑窗或发送限流均不足以构成该方向。

**联合攻击不能只是“再加随机延迟”：**攻击者从已合法获得的源版本中选择提交时刻，并优化恶意更新以穿过当前残差检测和预算约束；主实验允许攻击者知道防御规则及全部检测状态，但不读取最终测试集。对非光滑的限额与剔除采用离散时刻搜索和可行候选搜索，并验证攻击搜索预算增加后是否还明显变强。攻击目标分别设为降低干净性能、提高后门 ASR，不混成一个难解释的总分。

**主实验与扫描：**两个数据集完成默认异质性、默认延迟下的全部攻击；恶意比例、延迟上限 `{4,8,16}`、预算强度只在 CIFAR-10 的联合攻击下逐项扫描。另用一组关联时延/丢包轨迹检验网络 Future Work，不声称已经验证真实网络。

**必要消融：**完整版、去源版本条件、去受限历史更新、去滚动预算，外加上表“BRAFed + 同预算”的强对照。攻击也拆为“仅改更新”“仅改提交时间”“联合修改”，并固定恶意训练/提交资源上限。比较完整方法与简单限额基线，才能区分检测创新与减少恶意参与带来的收益。

规模沿用 T1 的 3 模块/2 集/100 端；P1 的 3 个复杂数据集不是本选题必须全部复现的门槛。

### 4. 预期能证明什么

**【基于文献基座的推断】**直接对应“P1 已做无根数据异步防御，但未充分检验恶意延迟与在线更新联合自适应攻击”的空白。该方向的贡献不能写成“首次无根数据异步防御”。

如果成立，可支持：在稳定准入身份、有限陈旧度和窗口良性统计仍有辨识力的条件下，源版本条件检测较少误拒慢端，贡献预算则限制漏检更新的累积影响；联合防御比单纯放宽延迟阈值或单纯限流有更好的精度、ASR 与速度权衡。

可以先分析固定窗口内的直接恶意位移：若存在 `f` 个固定恶意身份，使用实际施加到模型上的权重 `a`，则由裁剪和预算有：

\[
\left\|\sum_{i\in\mathcal B}\sum_{t\in W}
a_{i,t}\widetilde\Delta_{i,t}\right\|\le f\beta B.
\]

该界解释“频率不能无限放大影响”，但**不是总训练误差界**：它未覆盖恶意更新诱导后续良性轨迹变化、参考估计偏差和长期累积，也不保证攻击被检测出来。进一步的误差分析须显式保留这些项。

**否证条件：**若 BRAFed 加同样预算已经达到同等效果，或性能提升完全来自大量抛弃慢端，则源版本检测的研究假设没有被验证。仅在随机延迟下领先而败于联合攻击，也不算填补此空白。

### 5. 最可能在哪里翻车（风险预判）

| 失效条件 | 原因及规避 |
|---|---|
| 攻击者掌控某个到达窗口的多数更新 | 无根统计参考会被污染，即使注册恶意端仅 30%。记录窗口恶意质量；服务端版本/身份预算可缓解频率优势，但不能保证所有窗口都有良性多数。参考不足时等待或缩小更新。 |
| 客户端真实分布突然变化 | 历史偏差不再稳定，合法漂移可能被识别为攻击。设置良性变化对照，允许受预算约束的历史重建；不要把这一例外解释成已解决概念漂移。 |
| 攻击位于低维投影的盲区 | 压缩残差可能丢失攻击信号。补偿后的完整向量仍需裁剪，加入按层投毒压力测试；若必须用过高投影维度才能防住，要报告开销与取舍。 |
| 预算严重降低吞吐或少数类参与 | 快端和慢端的数据可能不均衡。报告固定时间与固定任务数两种结果，以及慢端类准确率；不能仅按聚合轮次比较效率。 |
| 冷启动即遭受持续攻击，历史也被慢慢改写 | 无干净预热保证。第一批即施加攻击，限制参考更新速率并测长时间低强度攻击；参考丢失时接受失败结论，不引入未声明的真实身份标签。 |
| 与已有异步攻击/防御重复 | **【补充一手检索】**PoiSAFL 已利用陈旧更新的容忍区间并操纵恶意上传频率，且讨论了参与控制防御。因此“发现延迟可掩护攻击”和“限制参与”本身已有先例；本方向须证明源版本残差与记忆预算的增量。[PoiSAFL 原文，§3–4、§6](https://www.usenix.org/system/files/usenixsecurity25-pang-xiaoyi.pdf)。 |

## 方向三：身份无关的行为记忆与受限知识蒸馏

### 1. 创新点假设

**【拟议设计／待验证】提出“行为记忆约束的鲁棒蒸馏”算法 D3，针对《非独立同分布场景下的联邦学习鲁棒性的优化研究_谈轩.pdf》的历史机制在身份更换下可能失效、《面向非独立同分布数据的个性化联邦学习算法研究_唐剑吾.pdf》的异构教师未建模投毒与本地双模型成本，以及《非独立同分布场景下的鲁棒联邦学习方法研究_王晨.pdf》的正常效用后门盲区，在统一输出空间中约束跨身份的累计知识注入。**

### 2. 核心思路

**三类线索及其证据。**

| 线索 | 证据与推导 |
|---|---|
| 相互批判 | 【来自定向查阅原文】T2 p51 用恶意参与会降低测试性能作为筛选依据；T1 p54 明确后门可保持正常数据高精度。这是可直接核对的目标冲突。**【基于文献基座的推断】**T1 的历史防御若依赖稳定端身份，在身份更换下可能失去累计证据；T4 支持模型异构，但未验证教师可信性。三角矛盾为“参数历史可防御但难跨架构 → 输出蒸馏可跨架构但可转移恶意知识 → 正常效用筛选未必看到后门”。 |
| Future Work 延伸 | 【来自定向查阅原文】T4 p80 §6.2 承认本地维护两个模型的算力成本，并提出减少协作蒸馏成本。本文采用每端一个私有模型、服务器维护共享输出记忆；这是沿降低本地成本的目标另行设计，并非复述作者提出的拆分学习方案。 |
| 通用机制嫁接 | 【拟议设计／待验证】嫁接统一后验表示、行为分组的时间记忆和受限蒸馏。记忆与预算附着在行为群组而非会话 ID 上，针对身份轮换造成的证据重置。 |

**显式范围：**所有客户端具有相同任务标签空间，但模型结构可以不同。服务器有一小份独立、无标签、来源可信的公共探针池；它不是带标签根集，也不是免费的外部资源。恶意客户端可任意提交输出、轮换会话身份，但准入机制约束每轮恶意参与槽位比例，不能无限制造同时参与的身份。该方案不兼容隐藏所有单端输出的标准安全聚合，本文不同时解决这一问题。

**模块 A：把异构模型转为可比较的行为指纹。**

每端在相同探针及其轻量扰动视图上返回类别概率。服务器统一概率截断、归一化和温度约定，以探针上的预测关系、跨视图变化构建低维行为指纹。比较的是模型对同一问题的响应，因此不要求 CNN、MLP 或 ResNet 的参数维度一致。

指纹保留多种良性模式，不能简单将小簇判为恶意，或将最大簇视为可信。概率熵只描述确信程度，不能作为教师诚实性的证据。固定探针用于跨轮比较，轮换探针用于检验对固定样本的过拟合；安全性不依赖攻击者不知道这些探针。

**模块 B：用行为群组承接历史和总贡献预算。**

服务器将当前指纹软匹配到少量历史行为群组，记录群组稳健代表、正常变化尺度和滚动贡献预算。相近的攻击输出即使换成新 ID，仍继承该群组的历史与剩余预算。无法匹配的输出进入“新行为池”，该池共享一个总预算，不能按新 ID 各领一份额度。

群组的异常度来自当前创新残差与过去变化的关系，不能仅因存在时间长就自动授予高信任。分组过程、阈值与初始化应采用与 ID 无关的确定性顺序，避免算法暗中继续依赖标识符。群组内的稳健中心只用于减少极端输出，不被解释为已证明该群组良性。

**模块 C：把行为预算转为逐样本的蒸馏权重。**

在每个探针上，对通过当前一致性检查的教师概率做有界稳健融合；群组总权重以及新行为池总权重均有上限。权重被压低后不把其余权重无条件归一到 1：剩余质量保留给上一轮教师分布，证据不足的样本跳过蒸馏。再限制共享教师分布的单轮变化，生成 `Q_t(x)`。

良性客户端只维护自身模型，通过：

\[
\mathcal L_i=\mathcal L_{\mathrm{local},i}
+\lambda\sum_{x\in U}v_t(x)
\operatorname{KL}\!\left(Q_t(x)\,\|\,p_i(x)\right)
\]

进行训练，其中 `v_t(x)` 来自同一行为记忆和贡献预算，反映该探针的证据充分性；不按攻击者自报“可信度”设权重。服务器可以训练一个固定结构学生用于统一评估，但客户端不再同时训练一个共享结构的全局模型副本。

**为什么能够协同？**A 产生跨架构、跨身份都可比较的证据，B 把证据积累与预算延续下来，C 将这一预算落实为“多少知识可以进入下一轮”。若只有蒸馏，异常知识仍可被传播；若只有 ID 滑窗，换身份可重置证据；若只有聚类而没有群组及新行为池总预算，串谋方可通过复制或分裂身份增加教师权重。完整方法始终围绕共享教师的累计变化控制。

**新意应落在哪：**会话身份变化不能刷新相似行为的贡献额度，同时允许正常异构行为保留。蒸馏、聚类或中位数单独使用都不是新算法贡献。该方案优先验证身份轮换鲁棒性，不声称能识别探针上完全不可见的任意后门。

### 3. 最小实验设计

| 项目 | 最小配置，均为拟议设计 |
|---|---|
| 数据集与模型 | Fashion-MNIST：MLP 与小型 CNN 各一半客户端；CIFAR-10：小型 CNN 与 ResNet8 各一半。每集只设两类架构；固定 CNN 作为服务器评估学生。 |
| 客户端与异质性 | 100 端，每轮 20 端；`alpha=0.1` 为主，`0.5` 补充；200 轮、本地 1 epoch、4 个种子。增加一组全部 CNN 的同构控制，不再加第三数据集。 |
| 公共探针 | 每集 1000 条独立训练池样本，服务器不使用其标签；固定部分用于记忆，剩余部分轮换采样。所有输出空间方法使用同一探针池及查询预算。不得从最终测试集取探针。 |
| 身份更换 | 默认每 5 轮轮换全部恶意端的会话 ID，但不增加恶意槽位；另设 20% 良性会话更换，防止把“新身份”本身当成恶意标签。仅 ID 改名与真实新客户端加入分开测试。 |
| 恶意比例与攻击 | 主设定 30%，CIFAR-10 补 10%/45%。固定触发器后门、分布式后门 DBA、自适应输出投毒。自适应攻击允许串谋方同时优化探针输出、行为分组规避与身份轮换；增加持续低强度攻击以检验预算累积。 |
| 对照 | 普通均值蒸馏、坐标中位数蒸馏、Cronus、T1 思路的“按 ID 维护输出滑窗”适配版、Cronus + 同样长度的 ID 滑窗，共 5 个。T4 提供异构与成本动机；不要求为此额外复现其整个 GAN 框架。 |
| 指标 | 服务器学生的准确率/ASR；只统计良性客户端的平均及最差分位准确率/ASR；良性输出误拒或有效权重损失；新行为池占用、身份轮换前后的攻击权重变化；每轮字节数、客户端训练时间和服务器开销。 |

**主实验：**两个数据集在默认异构、异质和恶意比例下运行无攻击与三类攻击。无轮换/恶意轮换/混合良性轮换的完整对比集中在 CIFAR-10；探针规模 `{200,1000,2000}` 和群组预算也只做单因素扫描。

**必要消融：**完整版；去行为历史、只用本轮输出；B 改为按 ID 记忆；C 改为通过检测后的无预算蒸馏；以及“稳健输出聚合 + ID 滑窗”的直接拼接对照。模块 A 的必要性用相同探针预算下的同构/异构实验验证，不通过非法平均异构参数来制造弱基线。

**特别重要的有效性检查：**在正式比较防御之前，先确认攻击确实能经由该蒸馏协议影响服务器学生或良性客户端。若普通蒸馏本来就不能迁移所选触发器，所有方法的低 ASR 不能证明 D3 有效；应改用能攻击共享输出通道的自适应目标，或放弃关于该后门的贡献主张。

该工作量取 T1 的 3 模块/2 集/100 端，加上 T4 的异构能力验证；不同时引入异步网络、生成器训练和模型参数聚合。

### 4. 预期能证明什么

**【基于文献基座的推断】**对应“本批文献未见 T1 滑窗 × T4 模型异构 × 跨轮身份更换，同时测后门 ASR/良性误拒”的空白。额外引入公共无标签探针池是有成本的假设，不能称为在 T1 原设定上无条件增强。

如果成立，可支持：在输出行为具有一定可分性、公共探针覆盖任务、准入限制恶意槽位的条件下，将历史与额度绑定行为可以降低身份轮换带来的防御退化，同时保留正常异构模型的知识贡献。

可先证明一个窄而清楚的协议性质：**固定输出、到达次序及随机种子，仅置换客户端会话 ID 时，D3 的分组、教师输出与行为预算不变。**这验证“ID 改名不重置历史”，但不意味着攻击者改变行为之后仍能被追踪，更不是无限 Sybil 身份下的安全证明。还可在给定恶意最终有效权重 `a` 时分析有界概率融合误差，但不能假定聚类天然保证 `a` 很小。

**否证条件：**若仅替换为 Cronus 就消除了身份轮换差异；或 D3 将大量良性新行为冻结才获得低 ASR；或所有基线都不能迁移后门，则需要收缩或放弃当前新意叙述。

### 5. 最可能在哪里翻车（风险预判）

| 失效条件 | 原因及规避 |
|---|---|
| 恶意模型在所有探针及视图上完全模仿良性模型 | 仅凭这些输出无法区分，未知触发器仍可存在。加入白盒模仿攻击、轮换视图和探针失配实验；明确可观测性边界，不能承诺后门通用检测。 |
| 恶意方缓慢变更行为、分裂成多个群组 | 可以绕开简单的“相似即同一行为”规则。新行为池共享总预算、群组代表缓慢更新，并测试分裂/合并攻击；若最终仍获多数有效质量，稳健聚合不能兜底。 |
| 少数类良性模型被当作新异常行为 | non-IID 的多模态与攻击群组可能重合。保留多种良性模式、按客户端群体报告误拒，检验混合良性轮换。不能把聚类最大的群组自动认作良性。 |
| 历史教师已受污染，保留旧知识反而延长后门 | 预算限制传播速度，不会自动清除已学后门。加入攻击停止后的恢复曲线，允许过期记忆淘汰和在证据不足时停用蒸馏，而非无限保留旧教师。 |
| 输出交换节省参数通信，却提高总成本 | 探针前向计算与蒸馏训练可能不便宜。将查询、训练和字节数全部计入；仅用两种架构、固定探针预算验证，避免再加入生成器。 |
| 将“异构鲁棒蒸馏”误当首创 | **【补充一手检索】**Cronus 已以黑盒知识迁移支持异构协作和投毒防御。因此该方向必须对比它，候选增量只在跨身份行为记忆与累计贡献控制。[Cronus 作者论文摘要](https://arxiv.org/abs/1912.11279)。 |

## 三个方向共同的实验约束

1. **资源与信息对齐。**同一方向的各方法共享数据划分、客户端抽样、训练预算与攻击预算。根数据、验证数据、公共探针、先验恶意上界均单独列出。需要 `f` 的基线得到同一预设上界，不能偷偷使用逐轮真实恶意数；真实身份只用于离线指标和明确标记的理想参考。
2. **测试集隔离。**根训练、审计、公共探针和调参数据都来自预先隔离的训练/开发池，最终测试集不用于权重选择、检测阈值或攻击优化。先固定开发场景和调参预算，再在未参与调参的攻击/偏斜条件下测试。
3. **攻击强度可核对。**写明攻击者知识、控制对象、训练样本投毒比例、触发器、更新缩放或范数预算、攻击起止轮次；自适应攻击针对每个防御重新优化，不能只用为另一方法生成的攻击样本。搜索失败不能自动当作防御安全。
4. **联合报告效用与安全。**ASR 在非目标类别的触发测试样本上计算，报告分母，并与干净准确率并列；按类别或客户端群体分解良性误拒。导致模型整体失效的防御，即使 ASR 较低也不能算成功。
5. **配对重复与消融。**主结果采用相同的 4 个种子，报告均值、标准差和配对差值；消融保持资源一致。除逐个删模块，还要有最接近的直接拼接基线，以验证模块间确有依赖关系。
6. **先做可否证的小试。**每方向先只用一个数据集、一个关键攻击和一个强基线检验核心变量；通过后才扩为两集。方向一先检验类别约束相对类别均衡根训练的增量；方向二先检验源版本检测相对 BRAFed 加限额的增量；方向三先确认后门/输出投毒可迁移，再检验 ID 轮换增量。本文的规模要求不是要求一开始就跑完所有扫描。
