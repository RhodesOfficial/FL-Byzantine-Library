## 2. 实际实现与兼容边界

- RFA 保留均匀 alpha、零初始化及原 T 轮距离／加权／归一化递推。最后一轮结束后直接捕获刚产生返回 z 的 beta、分母和归一化权重；不在返回 z 上重算距离，也不改写聚合向量。
- `last_client_weights` 是不可变独立 tuple；`last_contribution_trace` 是冻结记录，含调用编号、输入顺序指纹、输出指纹、shape/dtype/device、T、nu、最后 beta 和分母。首次／失败调用权重与记录为 None。
- helper 默认六参数调用仍返回三项；仅显式 `return_weights=True` 返回第四项。RFA 默认仍返回同形状、设备、类型 Tensor。
- 旧两条 beta 历史和两个均值字段保持位置分组、跨迭代历史语义，标注 legacy。首次／失败状态读取安全；不把权重向量放入旧统计字典。
- 新同步边界验证同次记录、实际更新及可信接收 ID，再记录 `C_i=-w_i*u_i`。缺失／旧记录／映射错误／重构错误会 raise，清空实例贡献记录、桥接记录和本次摘要。可选旧 getter 异常仍返回空统计，不能吞掉强制贡献错误。
- 模型仍由原 `_model_from_update` 执行参数减法。float32 复用独立两层数学核验，q 不从贡献残差求得；CPU/float64 使用 `atol=1e-10, rtol=1e-8`。未登记的模型写回 dtype/device 明确拒绝，不自动放宽精度。
- RFA 缓存键补入已有 T/nu 选项；不新增训练参数或改变参数值。单独日志字段 `byz_rfa_contribution` 保存身份贡献记录的独立副本；旧 `byz_aggregator_stats` 保持标量字段。
