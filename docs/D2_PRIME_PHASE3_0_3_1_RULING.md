## Q1．攻击知识、能力与反馈

**[裁决] 选“因果状态白盒”，不选只知道公开超参的半白盒，也不授予未来信息。**

1. **可读**：当前已发布模型/版本、公开防御公式及全部防御超参；已经到达服务端的更新；当前防御状态。对D2′包括有效源快照、当前`mu/sigma/e`、账本与已经算出的`g/z/lambda`；对其他方法包括其实际存在的对应状态。可读自己控制的客户端数据和任务。缺少的防御状态记“不适用”，不得凭空构造D2′门控替代目标方法。
2. **不可读**：尚未到达的诚实上传、未来模型/反馈、诚实原始训练数据、根池、开发/最终评价样本及标签、评价M。快慢名单、其生成种子1801、调度/延迟随机源的种子801/2801+c及内部状态不进入攻击观察面；不能通过读取登记文件重新生成名单。允许从已经观察到的到达历史推测延迟，推测不等于获准读取真值。
3. **恶意身份**：固定30/100，开发seed101；复用1.4的恶意身份选择及名单，跨方法保持相同。名单不根据快慢身份重抽，也不强行做15快＋15慢。攻击者知道自己控制的身份，因此能识别其余身份不是同谋；防御不能读取恶意真值。[S7]
4. **时间能力**：冻结的原生延迟仍决定每个任务最早可用时刻。恶意端可在该时刻之后继续持有上传、选择释放时刻或故意不响应至过期；不能早于原生可用时刻送达，不能修改诚实端延迟、任务号、源版本、槽数、期限或服务器时钟。一身份一未终结任务保持；扣留仍占槽。所有已签发任务仍执行原定完整本地训练，不能靠少训练伪装同任务预算。
5. **向量能力**：允许直接替换上传模型差，不限于翻标。攻击侧原始向量上限固定为`10*B_M`，只是本次有限攻击族的资源边界；不代表服务器都使用B_M裁剪。攻击者知道B_M和z_cut=6，可在这一知识下选向量。
6. **反馈**：每条恶意任务在其原生可用时刻只获得一次在线搜索机会。同tick先完成到期处理并收集实际已到达的信息，再作攻击决策，之后才允许该tick的真实开批；多个新可用恶意任务按task_id排序决策。该边界可读当下状态，反馈延迟为**0额外tick**，但不得读取尚未发生的本tick提交结果。该任务选定后不再改向量或释放计划；后续任务可利用新的已发生反馈重新优化。

[事实] 不向算法泄露快慢真值、期限/版本检查、独立外生随机源和40槽已在2.1冻结。[S8] **[推断] 把“已在GPU算完但运输尚未到达”误作白盒可见，会获得一个超出本合同的未来更新预言器。** [S6]

**损害由Q6的独立评价裁定，不能由“向量非零”“与良性均值反向”“候选损失上升”代替。** [事实] D1总结明确活性不能替代有害性，而且其最终翻标校验确实测到了损害；不能把“完整D1失败已证明攻击太弱”当作本关已知因果结论。[S9]

## Q2．联合攻击的数学合同

**[裁决] 固定为一个有限候选、逐任务在线自适应的联合攻击族，登记名`causal_joint_32_v1`。不另跑ALIE/IPM/翻标矩阵。** 以下是目标及可行域，不规定代码组织方式。

### 优化数据与向量候选

- 攻击优化集只从**30个恶意客户端原有训练索引的并集**产生：按原始数据索引排序，每类取前6个，最多60个；缺某类则不补用其他数据，对实际存在的类别等权。保留真实训练标签；不移走本地训练样本，不改原任务划分。索引、类别计数和哈希在smoke前登记，与两个评价部分、根池分别核对无交集。该集是攻击者训练数据子集，不称独立验证集。
- 在一次决策时刻t，`mu_vis`为最近至多20条**已合法到达、非同谋**原始更新的均值，排序键为到达tick、task_id；没有此类记录时用本任务正常本地训练产生的模型差。只保存当前及过去可见内容，不按未来是否被防御接受来筛选。
- 攻击损失使用固定的确定性输入预处理和模型评价模式，候选之间不重新抽样、不做随机增强；参数梯度可计算，但不训练模型、不改变任何客户端本地训练随机源。它与正式M评价分开，后者的样本/标签不能进入搜索。
- `v_1`为`mu_vis`的单位方向；`v_2`为当前已发布模型在攻击优化集上**类别等权交叉熵**梯度的单位方向。梯度最多计算一次，允许对模型参数求导，不对最终测试误差求导。方向范数≤1e-12时依次用另一方向、本任务正常模型差方向；全部为零则使用零方向，照实记录失活，不另搜索随机方向。
- 候选上传量：

\[
u_{d,\gamma}=\operatorname{clip}_{10B_M}\bigl(\mu_{vis}-\gamma B_M v_d\bigr),\qquad
d\in\{1,2\},\quad\gamma\in\{0,0.5,1,4\}.
\]

这里`u=theta_source-theta_uploaded`，服务器实际更新方向为减u；反向均值和损失梯度方向均用于寻找有害上传。八个登记候选中的重复值仍占候选名额，不借去重补做额外搜索。

### 时间候选与联合目标

- 对每个向量同时比较四个时间动作：**立即释放、额外等4tick、额外等8tick、不响应至过期**。若等待会抵达或越过`issued_at+32`，该动作的结果就是过期；不得临时延长期限或移到过期前一刻。同一任务总共8×4个联合候选。
- 每个候选在相同的可见前状态上评估。设`F_t^{32}(d,gamma,delay)`为未来32tick的**因果代理轨迹**：包含当前已到达合法候选、已登记的同谋待释放任务，以及正在评估的候选；没有新任务签发，也没有任何尚不可见的诚实到达。期间按目标方法自己的开批、过期、陈旧度、过滤、预算、参考写回和版本规则演化；不能只改时间字段而仍按立即释放的批次计算分数。候选结束后恢复原前状态，任何费用、随机状态或参考变化都不能泄入真实运行。
- 代理中的“没有未知未来到达”不等于真实训练预算已耗尽，不得据此提前启用尾批规则；只有真实前状态已满足尾部条件时才按尾部条件处理。只读分支不执行新的诚实本地训练，不为未知诚实更新造代理值。
- 目标固定为

\[
J_t(d,\gamma,delay)=L_{adv}\bigl(\theta[F_t^{32}(d,\gamma,delay)]\bigr),
\]

即最大化代理轨迹末端、攻击者自己训练数据上的类别等权交叉熵。所有候选用同一数据、同一32tick终点；并列时依次选更早释放、更小gamma、更小方向编号，过期动作排在有限释放之后。不读取实际未来轨迹，也不以最终M挑当次候选。
- 选中的向量与时间动作在真实运行中各执行一次；真实未来诚实到达照常发生。后续任务重新读当时状态，构成在线反馈自适应，而非整场只搜索一次。

**[推断] 该目标能将时机通过批次组成、版本、预算释放及参考变化与向量联系起来，但代理轨迹省略未知未来到达，不能保证其候选排名等于真实最终损害排名。** 这正是必须单独运行Q6实际资格考的原因。论文只能称“所定义有限预算的因果白盒联合攻击”，不能称全空间最优、搜索饱和或最坏攻击。

**关于时序实际启用：**smoke的固定状态证据必须显示：保持向量不变，至少两个合法时间候选产生不同的释放时刻，并在一个有竞争到达/预算边界的用例改变实际处理路径；完整运行记录实际选中时间动作。若无防御平均的最优动作全为立即释放，不强迫它选更差动作，也不据此声称时序造成了额外损害；但只搜索向量、时间维固定不变的实现不符合合同。资格考验证的是联合搜索器及其对平均的损害，不是给每种动作设命中率。

## Q3．Q的单位、数值和冻结

**[裁决] `Q=32次联合候选评估/一个实际执行过本地训练且到达原生可用时刻的恶意任务`。该任务固定枚举8×4候选，然后停止；没有“无改进N步”，没有Q/2Q，没有隐含重启。**

- 一次候选评估包含一条Q2规定的32tick代理轨迹及一次终端损失评价。代理轨迹中间调用多少次防御不另记成新的候选，但必须记录，不能延长预测跨度。
- 另有**每个决策最多1次攻击优化集梯度计算**，与候选费用分别记账；不得隐藏PGD内循环、额外训练或测试集查询。每候选最多60个样本前向，每次梯度最多60个样本反向。
- 固定训练预算12,000任务，因此整单元候选硬上限为`32*12000=384000`，梯度次数上限12,000；实际只为有资格决策的恶意任务使用，报告实际值。**公平性为相同每任务额度、相同总上限和数据访问规则，不冒称各方法实际查询数必然相等。** 时序改变恶意任务的实际执行次数应如实列示。
- 重复、不可行或过期候选也占名额；错误候选不能无限免费重试。未能得到任何有限候选分数记搜索故障，停下修工程，不能自动以原始上传替代并报攻击通过。数学上合法、未产生模型写回的候选仍可有正常损失分数。
- **在3.0规格登记、首次smoke之前冻结**：Q、梯度额度、候选集合、数据、代理跨度、并列规则及停止规则；3.1 PASS后再封存实现哈希。比“D2′收益比较前冻结”更早，不等看D2′成绩才定。
- [推断] 32来自本合同2×4×4的有限可行域，是预登记资源选择，不是经验上已证实充足的预算。smoke只检验正确性和资源账，不按损害大小改Q。

## Q5．BRAFed复现规格与预算适配

### 5.1 原文机制必须完整保留

**[裁决] 对照名称写为“BRAFed（原生机制、统一协议适配）”与“BRAFed＋模型预算（统一协议适配）”。“原生”在这里表示无D2′门控/预算；不表示照搬原论文数据、学习率、轮数和延迟实验。** 这与当前统一任务/协议要求同时满足；若以后要求论文表2所有实验参数原样复现，那是另一项实验，本关没有授权加入。

[事实] 原文规则如下，不能只取其中的MD过滤而称BRAFed：[P1–P5]

1. 本地损失`CE + epsilon/2 * ||theta_local-theta_source||²`，算法2上传`u=theta_source-theta_local`。
2. 当前组全部输入计算mu和协方差；原文实现说明使用**对角近似**，不是必须构造797962平方矩阵。MD按式(3)计算；当前门槛为`mean(MD)+k_det*std(MD)*exp(-lambda_B*t)`。
3. 旧源更新使用当前组已计算的mu/covariance和放宽门槛`alpha*T_online`。**不在筛后当前组上重算mu/covariance**；投影用的方向m才是筛后当前组均值。原文正文措辞与算法1注释之间以显式参数流及“复用已计算统计”为准。[P2–P3]
4. 筛后延迟向量按`m·u>0`分非冲突组，其他归冲突组；对冲突组均值使用`P_m=I-mmᵀ/||m||²`，去除沿m的分量。
5. 三组均值权重`(alpha0,alpha1,alpha2)=(0.6,0.25,0.15)`，公式(7)更新还要乘外层学习率eta_B。原文表2为eta=0.01；这不是D2′的eta_M=1。[P4–P5]

### 5.3 逐端实际贡献契约

**[裁决] 与RFA相同，采用本事件最终模型位移的可核验代数分解，不要求跨所有非线性统计的因果归因。**

对一次已完成检测/分组的事件，令筛后组为G0/G1/G2，公共投影为P_m。定义

\[
v_i=\begin{cases}u_i,&i\in G_0\cup G_1,\\P_m u_i,&i\in G_2,\end{cases}\quad
a_i^{(0)}=\eta_B\alpha_j/|G_j|\quad(i\in G_j),\qquad
\Delta\theta=-\sum_i a_i^{(0)}v_i.
\]

被过滤任务的实际系数为0。由于同一事件P_m固定，投影组均值等于逐端投影后取均值。**可以输出按任务绑定的变换后向量和系数；不能声称一定存在对原始u_i的同一组非负标量权重，也不能用均匀权重代替。**

输出契约至少包含：身份/task/source/batch、原始输入指纹、分组/过滤结论、统计和投影所依据的批次、v_i指纹、外层步长、a0、最终a、实际`-a*v_i`和总位移。原生版最终a=a0；两版均按已有两层写回规则核验，不把舍入差分摊给客户端。[S16]

**[推断] m、筛选集合及投影本身依赖多个客户端，所以该分解限制的是直接模型写入项；它不限制某客户端通过改变统计/投影而间接改变其他客户端的系数或方向。** 不能把“逐端可重构”写成“全部因果影响都已计量”。

### 5.4 预算版的唯一适配

**[裁决] `H=33`，模型额度`beta_M=0.4125/1.1=0.375`，采用同一模拟时间滑窗、身份和任务终态规则。**

- 无余额身份等待，排除在本事件BRAFed统计之外；部分余额仍按同一候选规则参与。等待不预留，过期不释放从未扣过的费用。
- 进入BRAFed统计前逐端把原始u裁剪到B_M；后续检测、分组和投影按5.1/5.2执行。原生版没有这一裁剪；名称及差异表必须承认预算版包含匹配影响上限所需的模型裁剪。
- 对上述真实a0，令`lambda_i=min(1,L_i/a0_i)`、`a_i=lambda_i*a0_i`，费用只记`q_i^M=a_i`。正系数但零向量仍按系数契约收费；不能改成向量范数收费或先按归一化组权重扣费。
- 统计、组别、P_m与组分母在此次缩放前固定；不在缩放后重算到恰好用满额度，也不重新归一化。最终写回`-sum(a_i*v_i)`，原子发布模型/账本和任务终态。
- 原生BRAFed没有D2′参考通道，**不伪造b_i，不扣0.1倍“参考费”**。上限审计是每身份窗口`sum(a_i)<=0.375`；投影不扩张L2范数，裁剪后`||v_i||<=B_M`，因此直接模型项有对应上界。它不声称把BRAFed本批非线性统计的间接影响也纳入预算。

[事实] 上述模型额度转换及不虚扣参考费用是原3.0和裁剪版的明确要求。[S10–S11] **[推断] 与D2′匹配的是直接模型影响上限，不是实际累计步长；BRAFed原公式的外层步长必须保留和披露，不能以同预算名义抹掉差异。**
