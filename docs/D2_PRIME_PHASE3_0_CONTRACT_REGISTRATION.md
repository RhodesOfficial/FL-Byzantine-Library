## 二、联合攻击数学合同（Q2）与 Q 规格（Q3）

登记名 **`causal_joint_32_v1`**，一个有限候选、逐任务在线自适应的联合攻击族。不另跑 ALIE/IPM/翻标矩阵。

### 2.1 优化数据

- 攻击优化集只从 **30 个恶意客户端原训练索引并集**产生：按原始索引排序，每类取前 6 个，最多 60；缺类不补；对实际存在类别等权。保留真实训练标签；不移走本地训练样本、不改任务划分。
- 索引、类别计数与哈希在 smoke 前登记，与两评价部分、根池分别核对**无交集**（已核对：60 样本，10 类各 6，均在客户端池内，与根池不相交）。该集是攻击者训练数据子集，**不称独立验证集**。

### 2.2 可见均值与方向

- 决策时刻 t，`mu_vis` = 最近至多 20 条**已合法到达、非同谋**原始更新的均值（排序键：到达 tick、task_id）；无此类记录时用本任务正常本地训练产生的模型差。只用当前及过去可见内容，不按"未来是否被防御接受"筛选。
- `v_1` = `mu_vis` 单位方向；`v_2` = 当前已发布模型在攻击优化集上**类别等权交叉熵梯度**的单位方向。**每决策最多 1 次梯度**；允许对参数求导，**不对最终测试误差求导**。
- 方向范数 ≤ 1e-12 时依次退化到另一方向、本任务正常模型差方向；全部为零则用零方向并如实记失活，**不另搜随机方向**。

### 2.3 向量候选（八个）

\[
u_{d,\gamma}=\operatorname{clip}_{10B_M}\bigl(\mu_{vis}-\gamma B_M v_d\bigr),\quad d\in\{1,2\},\ \gamma\in\{0,0.5,1,4\}
\]

其中 `u = θ_source − θ_uploaded`，服务器实际更新方向为减 u。八个候选中的重复值仍占名额，不借去重补做额外搜索。

### 2.4 时间候选与联合目标

- 对每个向量比较四个时间动作：**立即释放 / 额外等 4 tick / 额外等 8 tick / 不响应至过期**。等待抵达或越过 `issued_at+32` 即为过期；不临时延长期限。每任务共 **8×4 = 32** 个联合候选。
- 每候选在同一可见前状态上评估。`F_t^{32}(d,γ,delay)` 为未来 32 tick **因果代理轨迹**：含当前已到达合法候选、已登记同谋待释放任务、正在评估的候选；**无新任务签发、无任何尚不可见的诚实到达**；按目标方法自己的开批/过期/陈旧度/过滤/预算/参考/版本规则演化；候选结束恢复原前状态，费用/随机态/参考变化**不泄入真实运行**。
- 目标固定：\[ J_t=L_{adv}\bigl(θ[F_t^{32}(d,γ,delay)]\bigr) \]，即最大化代理末端、攻击者自己训练数据上的类别等权交叉熵。
- **并列**：max L_adv → 更早释放 → 更小 gamma → 更小方向编号；过期动作排在有限释放之后。不读实际未来轨迹，不以最终 M 挑当次候选。
- 选中向量与时间动作在真实运行各执行一次；后续任务重读当时状态构成在线反馈自适应。

### 2.5 Q 的单位、数值与冻结（Q3）

- `Q = 32 次联合候选评估 / 一个实际执行过本地训练且到达原生可用时刻的恶意任务`。固定枚举 8×4 后停止；无"无改进 N 步"、无 Q/2Q、无隐含重启。
- 每决策另记**最多 1 次优化集梯度**，与候选费用分别记账；每候选最多 60 样本前向，每次梯度最多 60 样本反向。
- 整单元候选硬上限 `32×12000=384000`，梯度上限 12000；只为有资格决策的恶意任务使用，报告实际值。
- 重复/不可行/过期候选也占名额；**未能得到任何有限候选分数记搜索故障，停下修工程**，不自动以原始上传替代并报通过。数学合法但未产生模型写回的候选仍可有正常损失分数。
- **在 3.0 规格登记、首次 smoke 之前冻结**：Q、梯度额度、候选集合、数据、代理跨度、并列规则、停止规则；3.1 PASS 后再封存实现哈希。

**可声称范围**：只能称"所定义有限预算的因果白盒联合攻击"；**不能**称全空间最优、搜索饱和或最坏攻击。

### 4.3 逐端实际贡献契约（5.3）

\[
v_i=\begin{cases}u_i,&i\in G_0\cup G_1\\ P_m u_i,&i\in G_2\end{cases},\quad a_i^{(0)}=\eta_B\alpha_j/|G_j|\ (i\in G_j),\quad \Delta\theta=-\sum_i a_i^{(0)}v_i
\]

被过滤任务系数 0。输出契约至少含：身份/task/source/batch、原始输入指纹、分组/过滤结论、统计与投影所依批次、v_i 指纹、外层步长、a0、最终 a、实际 `−a·v_i` 与总位移。原生版最终 a=a0；两版按两层写回规则核验。**可输出按任务绑定的变换后向量和系数；不得声称存在对原始 u_i 的同一组非负标量权重，不用均匀权重代替。**
