## 二、综合基准与204单元的重新定位

**以本次三篇为参照，典型展示尺度约60–70个不含seed的配置、15张结果图表；样本跨度为48–380配置、9–16张结果图表，含seed的完整训练总数无法给统一数值，明确4seed的样本可推算约256–356次。**这是小样本中位尺度，不是八篇论文乃至全领域的毕业标准。

必须纠正上一版给人的印象：**204并不能被文献证明为“典型硕士论文的几倍”。**它本身是51个配置格×4seed，与48或64–65格同一量级；相对明确4seed的样本，204约为其估算训练量的0.57–0.80倍。`204/48=4.25`混用了训练次数和配置数，不能作为倍数结论。

真正应裁剪的是：把54个开发单元、额外校准/归因/基线复现，以及204个确认单元都列为最低要求；又为这条路径设置过细的工程验收。论文样本支持“两个数据集、少量机制对照、复用同一批轨迹制作图表”；**不直接证明**D2′可以没有攻击校验、无需强对照或必然能毕业。

以下裁剪是针对用户时间约束的研究判断。恢复BRAFed两版后为25个正式配置格，仍比上述样本更聚焦；不能据此反称“75单元就是文献公认的硕士门槛”。

- **六配置→四配置：本次撤回，保留六配置。**BRAFed原生版及预算版均必须比较；源版本消融继续在主矩阵，去预算仍缩到第一集联合场景。B＋影响上限匹配预算这个关键控制不变。
- **4seed→3seed：可以。**在运行前定好3个并完整报告均值、标准差、逐seed配对差值，不用客户端数或轮次数充当重复数。删除“四seed配对95% t区间下限必须>0”的硬门，失去的是这项预设统计确认要求，不是获得新的显著性保证。
- **独立确认：不必另做昂贵确认矩阵，但保留开发seed与3个正式seed分离。**其成本是种子用途管理，不需要再增加一批训练。数据测试集是否已在历史中查看过仍如实披露；新seed不等于新测试集。

#### 剪裁后4.4的通过口径

沿用原指标、任务数与实际工作量对齐、2pp干净容忍、停滞和慢端定义，只有下列样本量/主张范围调整：

- 两集联合攻击中，D2′相对B＋预算的平均提升≥2pp，至少2/3 seed差值>0；B本身的结果完整报告，若优于D2′，不得写成超越基础稳健聚合的总体结论。**新增强对照硬门：在每个数据集，D2′相对BRAFed＋预算也须平均提升≥2pp，且至少2/3 seed配对差值>0。**分别核验两个对照，不合并数据集或按seed挑弱基线。未达到则4.4不能PASS；已有阶段4失败处置不变。
- 两集干净均值下降不超过2pp、单seed不超过3pp，`R_slow≥0.80`且无持续停滞；算法不变量全部通过。新增BRAFed原生版及预算版均纳入干净对照，D2′相对两版分别满足同一性能容忍。
- 第一集两项核心消融各平均提升≥1pp、至少2/3 seed为正；源版本对应慢端相对保留平均增加≥0.05。第二集虽有当前参考对照，但机制跨集结论只有其实际结果也支持时才写；无去预算对照不声称预算机制跨两集已分离验证。
- 攻击合法、活跃且实际损害有证据；必须披露失败seed、所有登记结果、实际计算量与未测范围。
- BRAFed原生版与预算版的机制核对、预算适配及每版重新优化攻击的证据齐全；适配版使用匹配的直接模型影响上限。原生BRAFed的逐seed结果和配对差值必须展示；若未胜过原生版，不能把胜过预算版写成胜过原生版。
- **上述是预先约定的实际效应/经验重复性门，不是统计显著性检验。**方向弱或消融不成立仍不能宣告成功。失败按原规则处理，不能临时删seed、调低阈值或追加到显著。

通过合并后的4.4即可围绕已支持范围写方法和实验章。允许复用日志形成约8–12张有信息的结果图表，不设置凑图表数量的通过条件。

## 四、裁剪损失清单与结论边界

| 砍掉的内容 | 必须放弃或限制的结论 |
|---|---|
| 五种保存位置、故障组合矩阵 | 多位置恢复已验证、广泛崩溃/故障容错；只能承诺已测安全边界的恢复 |
| 坐标中位数筛选、双开发seed、两个攻击强度全扫描 | 广泛基线排名、早期跨seed稳定性、恶意比例响应规律 |
| 零延迟完整训练、第二个正常时序 | 跨时延分布稳健；只保留零延迟数值退化正确性 |
| H/beta专门扫描/重复采集 | 参数最优性、灵敏度/可迁移范围；只支持固定校准规则 |
| Q/2Q与搜索饱和验证 | 近最坏白盒安全性、预算增大不再伤害；仅支持给定攻击器及Q |
| 固定步长匹配控制 | 已排除整体减小实际步长的替代解释 |
| 两个中间攻击场景 | 时序操纵的独立增量、跨多种攻击家族鲁棒 |
| 第二集去预算消融、4.5扩展 | 两机制均已跨集独立验证、强异质性/高恶意比例/窗口污染边界 |
| 第4seed、95% t下界硬门 | 原先的统计确认条件；3seed仅给经验重复与不确定性展示 |

**BRAFed不再属于裁剪损失。加回两版后，论文能/不能声称：**

- **能声称（结果通过时）：**在两个已测数据集、固定延迟条件、给定联合攻击器/Q和任务预算下，D2′相对BRAFed＋匹配影响上限预算具有上述可重复增量，且干净代价满足容忍；如相对原生BRAFed的结果也支持，可另行报告对原生版的经验优势及实际差值。
- **不能声称：**仅胜过预算版就优于原生BRAFed、优于所有异步拜占庭防御、达到近最坏白盒鲁棒性，或已经排除全局步长解释。匹配影响上限不等于匹配实际累计步长；BRAFed＋预算是本实验适配版，不能冒称原文版本。未增加的攻击场景、第二集预算消融和其他边界仍按上表限制。

**关于“缩写候选论文”的证据区分：**这里把它理解为“这次定向核读的候选论文/其压缩摘要”，并同时区分裁剪矩阵本身能支持什么。

- **所选论文能直接支持：**这些具体论文用了两集、相应方法/消融数量、上述图表；没有报告独立确认seed。不能由此推出D2′某关无用、无需近邻基线，或某实验量必然满足毕业要求。
- **75单元若通过可支持：**在固定身份、有限延迟、选定任务/攻击器/Q下，相对B＋同影响上限预算及BRAFed＋同影响上限预算有重复的性能增量；在第一集有源版本与预算组件的消融证据。原生BRAFed优势结论仍须其直接结果支持，可讨论慢端贡献和有界直接写入。
- **需要恢复对应完整矩阵/控制才可支持：**跨四场景成立、两机制均跨集成立、排除全局步长解释、跨恶意比例或异质性范围成立。BRAFed两版在现有两场景的比较已恢复，不再列为缺失。应恢复与主张对应的格子，不是机械认定必须把旧204全部跑完。
- **旧204也不能单独证明：**任意自适应攻击鲁棒、任意时延/恶意比例有效、长期参考不被污染。有限矩阵不是普适证明。
