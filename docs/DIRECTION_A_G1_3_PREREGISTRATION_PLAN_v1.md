## 2. 唯一推荐指标与事前阈值程序
每参考每类I_c={i:n_ic>0}，m_c=|I_c|，a_ic=n_ic/N_c；g_ic为完整CE头类均值，G_c=Σa_ic g_ic；p_i=q_i r_i由F格点公式和固定s_i、L_i计算。
Z_c=Σa_ic p_i，b_ic=a_ic p_i/Z_c，G_avail,c=Σb_ic g_ic，d_c=G_avail,c−G_c；报m_c、a/b权重、来源两两L2差异及max/RMS，概率不等不预设梯度偏差非零。
主尺度S_c=Σa_ic‖g_ic‖₂；主相对量ρ_c=‖d_c‖₂/S_c、绝对量A_c=‖d_c‖₂；另报A_c/‖G_c‖₂。S=0且全源为零时ρ=0；‖G_c‖=0时后者null并标零目标，A>0另标抵消，不加任意小分母。
N_c=0、Z_c≤0或非有限值停止，不删类重算；全类/尾类以固定类别分母macro平均ρ，同时报macro A和逐类值，无源不填0。m=1必为零；近同源以来源直径/S不超过专用数值包络标注，退化类不从分母删除。
目前无独立依据给实质ε_bias数值；G1.2的2e−6不能移作偏差阈值。唯一推荐“一个类样本等价的来源替换”校准，其研究解释先交审，不按主结果选择是否采用。
校准只读D/G，禁止输入s、L、r/p、事件及G_avail：枚举正来源对(i,j)，把目标权重从i移1/N_c到j，受控变化为(g_j−g_i)/N_c，冻结τ_c=max_ij‖g_j−g_i‖₂/(N_c S_c)；表示一个类样本的来源替换能产生的最大相对变化，不是主偏差。
S=0或单来源时τ=0并标结构退化，不单独据此声称实质偏差；ε_bias,all/tail为固定全类/尾类分母mean τ_c。此解释只对应样本分辨尺度，不直接对应分类收益最小量。
