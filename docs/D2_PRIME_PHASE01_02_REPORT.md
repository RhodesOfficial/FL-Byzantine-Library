## 实现与边界

新增独立 `d2_prime.protocol` 路径，未改easyFL、同步桥接、D1或旧零训练脚本。该路径实现任务台账、源模型保存、不可变快照元数据、事件堆、入口等待队列、容量受限候选缓冲及模型写回接口；尚未接入FLGo的真实训练入口。

任务状态：`issued → arrived → consumed/rejected`；未终结任务亦可进入`lost/cancelled/expired`。任务号单调递增；终态不回退。签发时绑定身份、源版本、时间、到期时间及配置哈希。未知、重复、跨身份、错误来源和非有限/错维度向量均不得增加模型写入或提交记录。

未完成任务包含在途、候选缓冲及入口等待；每身份最多一条，全局受配置上限约束。入口可暂存合法集中到达，但实际候选缓冲始终不超过K。任务终结释放槽位；旧回复或旧到期事件不能终结同身份的新任务。

事件排序键为 `(模拟时间, 类型优先级, task_id, 插入序号)`，到期事件先于同时间到达。`now >= expires_at`即过期。最大陈旧度含边界；超过边界结束任务。保留仍有未完成任务引用的旧源快照，无引用且非当前版本时回收。

`commit_model()`是显式模型写回接口：系数由调用者提供，必须满足`0 <= a <= eta_M/(1+staleness)/K`。固定分母K，小批次也不重归一化。它不伪造D2评分，所写ledger仅为模型通道消费记录，不是0.4的共享滑窗账本。0.4将提供真实双通道提交路径。
