## 数值对象、独立参照与候选选择程序

对象为同版本冻结 float32 特征上的完整线性头 CE 梯度（weight+bias 展平），主路径 float32 CUDA autograd。独立 NumPy float64 稳定 softmax：e=p-onehot(y)，∂W=mean(e⊗z)，∂b=mean(e)；特征和头 float32 值转换到 float64，参照不重新求 encoder。另记录 CPU float32、逐样本平均和分块全类结果。独立手算零 logits（p=1/3）夹具和非零 logits 标量有限差分核对解析式。

比较记录绝对 L∞、Frobenius/L2、reference L∞、scale=max(1,reference L∞)、normalized L∞。weight+bias共同规范，另记录各块误差和实际参照数组。候选 ε=max(8*u_float32,4*实测最大normalized L∞) 向上取一位十进制有效数字；u_float32=1.1920928955078125e-7（本记录按既有0.2记法使用机器 epsilon）。候选不冻结、不借用 logits 1e-6；用途限定本次平台、四点、eval 特征、CE 完整头与分块求和路径。

为防止靠扩大候选掩盖实现错误，运行前另定 smoke 排错界 normalized L∞=1e-4：达到则停止、报告不一致，不生成可接收数值依据。该界仅为工程排错保护，不是合同 ε_num 或正式通过门槛。形状/bias/缺类/状态恒等要求不由容差放宽。float64手算断言1e-12，非零标量有限差分1e-8。
