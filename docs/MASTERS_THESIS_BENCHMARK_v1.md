# 后续方向的硕士论文资格对照 v1

日期：2026-10-20。适用于后续非攻击方向的选题、范围收缩、实验验收和写作资格判断。

## 1. 固定作者约束

导师是纯放养：不指导选题、机制和中途技术决策，只在论文完成后判断是否够参加盲审。此前“有阶段性成果后沟通”的含义是做出结果后再送审，不是等待导师协助研究或提前认可方案。后续不得把“先问导师”“导师认可后才能实验”列为前置关口。[作者确认：2026-10-20]

**内部资格标准以 `master's thesis/` 的实际硕士论文为准。** Reviewer 负责将新方向与相关实例作具体对照；作者决定方向、时间和资源取舍。成稿后的导师判断保留在交稿计划中，不代替中途的研究判断。[作者确认：2026-10-20]

本文件把本地论文实例转为可执行的内部尺度，不声称这是院校公布的统一规章，也不把数量达标当作盲审必过。实例中的瑕疵、未解释假设或遗漏实验不能成为重复这些问题的理由。[推断]

## 3. 采用的内部资格尺度

|维度|新方向应交的证据|如何对标与避免过度要求|
|---|---|---|
|研究问题|明确一个自然压力、现有方法的具体失配、目标和适用范围；先证明该压力确实发生。|不能用“模块没见过这种组合”代替问题证据。A 的同概率场景作为必要条件反例保留。[文件] `DIRECTION_A_POSTMORTEM_AND_NEXT_STEP_v1.md` §2；[推断]|
|贡献组织|形成有联系、能分别分析的贡献部分；说明模块为何相互需要。|基座常见 2–3 个机制，T8 是两个递进研究部分；这是参考规模，不强行把单一完整方法拆成两个名字。[基座]；[定向查阅：T8，PDF 55 页]；[推断]|
|效果与比较|主指标、直接强基线、公平预算、原始逐种子结果和适用边界。|通常以 2–3 数据集、5–10 条基线、10–100 模拟端为规划范围；保留最可能推翻贡献的直接对照。范围之外应说明必要性或给出降级。[基座]；[推断]|
|机制解释|决定性消融或反例，把机制优势与多训练、多参数、多数据区分开。|基线数量不能替代关键消融；无需一开始做所有压力的笛卡尔积。[基座]；[推断]|
|理论|公式对象、条件和推论与实现一致；理论深度与主张强度匹配。|可用条件命题、误差分解或局部性质支撑，不把任意异构系统的统一收敛作为所有课题的必需品。[推断]|
|重复与不确定性|预先登记独立重复单位、固定参考关系、验证与测试用途。|T8 的四种子是实例；本项目的正式重复数按效应和预算事前说明，不为了照搬数量反复申请额度。[定向查阅：T8，PDF 47 页]；[推断]|
|成本与可执行性|测与所声称优势直接有关的时间、内存、通信；同时有完成论文的资源计划。|不要求每个普通任务建立逐运算精确界、全历史 I/O 证明或自定义进程监督器。[推断]|
|写作资格|能写出问题、方法、比较、机制分析和局限；每个核心贡献有相应证据。|工具验收、负结果、状态恒等式都可以成为材料，但不能自动充当完整学位贡献。[推断]|

上述常见规模来自本地样本，不是“最少必须有这些数量”的机械淘汰线。缩小数据集、基线或模块时，Reviewer 要逐项解释哪些主张也随之缩小、决定性比较是否保住、与哪篇本地论文仍具可比工作量。[基座]；[推断]
