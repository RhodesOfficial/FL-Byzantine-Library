## 1. 数学对象、尺度及退化

每参考每类固定I_c={i:n_ic>0}、N_c=Σn_ic、a_i=n_ic/N_c。g_i是封存float32完整weight(C,128)+bias(C)按固定顺序联合展平的129C维向量，其有限二进制值视为精确实数；不是未知的理想CE梯度。
格点概率p_i为F机制整数A/H/K所定义的有理数；Z=Σa_i p_i，b_i=a_i p_i/Z，G=Σa_i g_i，G_avail=Σb_i g_i，d=Σ(b_i−a_i)g_i，A=‖d‖₂，S=Σa_i‖g_i‖₂，ρ=A/S。
D=max_{i,j}‖g_i−g_j‖₂，τ=D/(N_c S)；同时报每对距离、max/RMS和A/‖G‖₂。完整头整体做L2，不能只取类行；尾类按D中N_c降序、同数类ID升序后floor(C/3)、floor(2C/3)分组，须待元数据核验。
N_c=0、无正来源、Z≤0、非法形状/dtype或非有限输入均拒绝；不删类。S=0须逐坐标确认全源严格为零，定义A=ρ=τ=0、u=0；浮点S区间碰零但不能证明结构零则标不可辨，不套该定义。
m=1或同源：d=D=τ=0，S照报；近同源仅按D/S≤专用数值包络标注，不删类。‖G‖=0时A/‖G‖返回null，A>0另标抵消；目标近零且界不能隔离0时此比值不可辨。
全类macro固定分母C，尾类macro固定分母C−floor(2C/3)（C10为4、C100为34）；ρ、A、τ及误差逐类等权平均。结构退化保留，缺失/不可辨不补0，任一必需项缺失则对应汇总未完成。

## 2. 四种误差及必须字段

|误差对象|所需字段/可证明口径|未知的具体影响|
|---|---|---|
|封存向量目标|消息身份、类/分母、完整形状、dtype、有限性、展平顺序、源/目标绑定及二进制SHA|对已定义的精确封存值没有额外“测量误差”；身份未验不能声称算到了此目标，更不能声称等于理想CE真值|
|float64运算|逐操作图/累加顺序、m与129C、操作数范围、除数下界、舍入模式、sqrt/求和实现、溢出/次正规处理|字段未闭合则算术界null，ε_num及通过结论不能冻结；与理想梯度差无关|
|历史独立实现差异|G1.2比较项与本源的对应、参照向量尺度R_i=max(1,‖g_ref,i‖∞)、逐项差/验收身份|2e−6只界主/参照差；缺R_i无L2数值界，缺参照真值界不能据此界理想梯度误差|
|连续概率近似|精确格点A/H/K及p_i、F的η_i≥|p_cont,i−p_i|、适用机制/单位|η未知则连续外推界null；不把它冒充精确格点运算误差或以经验频率代p|
历史维数h=129C：由‖g_i−g_ref,i‖∞≤2e−6 R_i只能推出差异L2≤√h·2e−6 R_i。若另有独立证明‖g_ref,i−g_ideal,i‖₂≤v_i，才有理想源界E_i≤√h·2e−6 R_i+v_i；v_i未知保持null。固定封存目标不需要假造v_i或重复扣历史差异。
算术证明的实现规范：精确整数/有理a、p作参照；每次加减乘除及sqrt以包含真值的向外舍入区间传播，平方和→sqrt给L2区间，max给D区间；区间端点需有正确舍入/有理平方比较证明，不能只比较两套float64。
也可先审定运算图后以u64=2^−53、γ_k=ku64/(1−ku64)（ku64<1）界顺序求和/乘积；须逐项计k、取绝对值和、另传播输入权重/除法/sqrt误差。现有math.fsum/平台不能仅凭函数名宣称满足某图；实测最大差/反序差只作回归证据。
下文帽号为近似值，E为已证明的绝对界；固定封存目标取源扰动E_i=0只因目标定义精确，算术E不为0。若讨论历史差异或理想目标则另标对象、代入其E_i，不与固定目标结论混报。

## 3. 传播、可辨性与盲校准

记q_i=b_i−a_i。C可用E_d≤Σ|q_i|E_i+E_d,64，E_S≤Σa_i E_i+E_S,64，E_D≤max_{i,j}(E_i+E_j)+E_D,64；权重a/b的运算误差另由区间乘法纳入各64项，不能只记累加误差。
E_A≤E_d+E_norm,64；S_−=Ŝ−E_S>0时，E_ρ≤E_A/S_−+|Â|E_S/(Ŝ S_−)+E_div,64；N_c精确时E_τ≤E_D/(N_c S_−)+|D̂|E_S/(N_c Ŝ S_−)+E_div,64。N_c S不得换成随机返回数。
对A/‖G‖同样传播：E_G≤Σa_i E_i+E_G,64，目标范数误差另加norm项，分母下端须>0。分母不可辨只关闭该比值/对应必需判据，不任意加小常数。
u=d/A（A>0）。若Â−E_A>0，方向界E_u≤2E_d/(Â−E_A)+E_normalize,64；否则方向不可辨。精确d=0定义u=0并报全向残差，用下述非零固定方向测试检验通道，恒零投影不能作为验证器证据。
每seed W=mean X−mean X0。设‖Ŵ−W‖≤E_W、‖W‖≤R_W，则用E_T≤(1+E_u)E_W+E_u R_W+E_dot,64界T=〈u,W〉（‖u‖≤1，Ŭ单位化误差须包括）；E_P≤E_T/S_−+|T̂|E_S/(Ŝ S_−)+E_div,64。主/对照各自Y及向量残差同样传播。
对任意X=Σh_i g_i，h_i=a_i mean(J_i)/Z，源项≤Σ|h_i|E_i，权重/除法/均值/sqrt误差由运算图区间给出；X0换共同p0>0，E_W≤E_X+E_X0+E_sub,64。可用R_W≤M(1/Z+1/p0)，M=max‖g_i‖；可辨下界必须先证明。
B只读D/G，不读s、L、p、主b/Z或事件；可用Σ|b−a|≤2给E_d,source≤2max E_i，及E_D≤2max E_i+算术项。Z≥z_*、p0≥p_*的项保留符号参数，不能在B偷看真实p；C才代入并检查分母。
连续项t=Σa_iη_i；Z>t时‖G_avail,cont−G_avail,grid‖≤2Mt/(Z−t)，相对界除以已证明S下界；否则连续近似不可辨。精确格点目标不扣连续项；候选的连续外推及主保守通过另扣此项，不扩大外推范围。
如需外推到连续机制的随机投影，另将X/X0权重变化与方向变化逐项传播；没有该证明只报告固定格点事件核验，不能把解析近似界直接当完整随机投影界。
固定macro误差为逐类E的固定分母平均，禁止用独立性假设开平方缩小。B只算τ及其区间、均匀/正负替换对照；ε_bias为候选mean τ的实质尺度，须连数值包络/采用端点规则交审冻结，不能按主结果选择。
ε_num为上述对象明确的解析、投影/区间端点及必要连续项的包络记录，不是一个套用于所有量的2e−6。当前所有待测实数仍null；下文门槛符号θ仅指将来审查冻结的相应ε_bias，不自行赋值或改候选严格门槛。

## 4. 同流配对与八项交集

保留seed 2026102300/2026102400/2026102500，各32 attempts，最大3seed；每attempt按20端ID顺序及F原抽样/消费顺序，邀请无放回20选8，PCG64(seed+1/+2/+3/+4)对应邀请/在线/掉线/jitter。跨三速度/四参考/均匀对照复用底层流，不改变原消费顺序，本单不生成轨迹。
X_tc=Σa_i J_ti g_i/Z_c，X0_tc=Σa_i J0_ti g_i/p0；空返回X=0照计，p0为共同邀请×在线×存活概率且K=N。E[X]=G_avail，E[X0]=G；端间可相关，不能据20端增加重复数。
Y_sc=〈u,mean_32 X_sc−G〉/S，Y0_sc=〈u,mean_32 X0_sc−G〉/S；主P_sc=Y_sc−Y0_sc，解析期望ρ。先按固定类分母得到P_s,all/tail，再对3个seed计算μ=ΣP_s/3、SD=√(Σ(P_s−μ)²/2)，I=[μ−t·SD/√3,μ+t·SD/√3]，t=t_.975,2=√(722/39)≈4.30265（由df=2的F(t)=1/2+t/(2√(t²+2))解得）；代码近似常量误差也须包入端点界。
若seed汇总误差分别e_s，μ误差≤mean e_s，SD误差≤√(Σe_s²)/√2；故每个区间端点数值误差E_I≤mean e_s+t√(Σe_s²)/√6+端点计算误差。方向/尺度在所有seed共用仍须照扣，不假设误差互相抵消。
同一汇总用解析ρ̂及其界E_R、区间[L,U]及端点界E_I：解析包含为L−E_I−E_R≤ρ̂≤U+E_I+E_R（含等号）；通过还需ρ̂−E_R−E_cont>θ且L−E_I−E_cont>θ。主保守外推所需连续项未知则该通过项未完成。
解析包含与严格下界必须用同一个配对统计及对象；如已把某误差纳入E_R/E_I，不再次扣同项。所有正来源同p的格点解析d严格零，要求数值区间含零；随机均匀对照只核验期望/包含，不要求每seed零。
SD=0返回点区间并报退化，不能声称已证明随机方差0或精确覆盖；空attempt列表非法，32次全空仍返回投影/向量残差。任一必需分母、误差或项缺失则不通过；不删退化类或更换统计。
tail_slow四参考×全类/尾类=八项，全部满足才整体通过；random/tail_fast逐项报告配对差异，不预设更小。边际95%依赖seed独立及seed均值近似正态，不是八项同时95%，四参考/32attempts也不是额外独立seed；不追加重复。
