## 预选的实现统计口径与理由

- 切分工具：A 专用 NumPy `Generator(PCG64)` 索引生成器，离线读取官方 CIFAR pickle，保存统一 JSON；不调用旧 D1/FLGO partitioner，避免强制根数据和 IF=50。validation 从官方 training pool 每类先留固定数，LT 只作用于剩余最终 training pool，无服务器 root。原始索引以 `official_train:i` / `official_test:i` 命名空间区分，同号跨源不是同一条记录；全局 test 与客户端 test 是同一官方 test 集的两个评价视图，允许此唯一显式重叠。
- IF 定义：最终训练类 c 的目标 `max(1, floor(H * 100**(-c/(C-1))))`，按类 ID 0..C-1 递减；H 为上表头类上限。舍弃未选官方训练索引须入表。实测 IF 另报 `max(N_c)/min(N_c)`，不可只报构造参数。
- α 定义：对每个类别独立抽 `p_c ~ Dirichlet([0.1]*N)`，不乘全局类频率；将该类最终训练样本数按最大余数法整数分配（余数并列按端 ID），随机排列类内索引后分给各端；不强制最小类数、不重抽、不平衡端容量。空端应显式记录。
- 独立客户端测试：逐类打乱 official test 索引后轮转均分给 N 端，独立于训练划分；候选任务每端 C10=500 / C100=500 图，完整类别覆盖。smoke 每端每类 2 图。测试分配的均衡身份须保留，不能声称复制本地训练分布。
- 模型：复用 `models/ResNet.py` 的 `ResNet_3Layer(BasicBlock,[1,1,1])`，通道 32/64/128，现有 option-B shortcut、128 维 encode、有 bias 的线性 head。旧 forward 返回 log_softmax；A adapter 明确返回原始 logits，交叉熵使用 logits；另外对旧 forward 作 log_softmax 兼容核验。BN 的参数和全部运行缓冲进入版本身份，测量用 eval，无更新。
- 变换：无随机增强；RGB uint8 /255，C10 与现有口径一致的 mean=(0.4914,0.4822,0.4465)、std=(0.247,0.243,0.262)；C100 mean=(0.5071,0.4867,0.4408)、std=(0.2675,0.2565,0.2761)。训练/验证/测试同变换，后续改变必须重新记录版本。
- ε_num 选择程序：报告 L∞ 绝对 logits 差、Frobenius 差、以 `max(1,||reference||∞)` 归一化的差、重复计算误差和参考范围。候选量取 `max(8*float32 machine epsilon, 4*实测最大归一化差)`，并向上取十进制有效位；另给绝对判定式。若系统性偏移或独立参照失败，不用该公式放宽掩盖。仅候选，不写成冻结值，也不用于梯度/恢复口径。
